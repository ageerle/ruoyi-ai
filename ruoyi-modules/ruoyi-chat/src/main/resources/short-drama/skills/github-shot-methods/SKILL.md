# GitHub 导演方法 · 素材职责与镜头接点

仅补充当前分镜、细化和提示词阶段，沿用本项目结构与审阅。先明确本段观众应获得的信息，再落实身份、空间、动作、受力结果和对手反应；摄影写起点、速度、主体关系与终点，不堆互相冲突的运镜。
角色、地点、动作视频与声音样本分别负责其指定范围，参考中的无关身份和剧情不继承。首帧可选，不默认补图；无首帧时从已批准资产和构图规划展开。连续段继承具体姿态、手物接触、道具状态和运动方向；已完成结果不回退，机位变化不等于换姿态。
原对白逐句保留声源与顺序，听者反应接住语句；音色、内容、声音自然度与口型同步分开检查。正文连续叙述，预算独立存 timing，参数来自本项目当前模型目录与供应商适配。
