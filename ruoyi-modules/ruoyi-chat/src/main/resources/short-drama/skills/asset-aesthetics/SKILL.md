# 资产审美业务规则

按当前题材、时代、地域、身份和画风制作，不能把明代县令模板套到其他项目。身份/场合决定帽、领、叠襟、袖、腰带、下摆、鞋、纹样；史料不足标设计约定，不混同公服品色与常服补子。原已批准身份、服装、建筑成长阶段与连续性不被审美升级改写。

先写轮廓与体积，再主辅点睛色，再材料。人物脸型、年龄、体型、姿态各有差异：自然眉骨鼻梁颧颌体积，眼睛明亮不过大，皮肤柔和不蜡，头发先大束后少量碎发。棉麻漫反射与可见织纹，绸只柔和窄高光，皮革硬度和局部磨损，木材有构造与适度纹理，铁冷灰、铜暖褐。不能所有材质同一湿塑料高光。贫穷表现为普通材料、局部修补与节制陈设，不是遍身泥污和破洞；富裕不等于满屏金雕。

人物定妆仅单一身份、自然静态姿势和清楚完整服装，比例可读、双手有形；非人形CG按原设定，不能人形化。空间母版写人尺度、入口动线、前中后景、门窗桌椅固定关系、功能器物与光向；支撑落地，旧墙局部修补，不空成泥墙或宫殿。道具保持用途、尺度、连接和支撑，材质与主人身份相符；虚构武器不增加制造参数配方。

实际首帧以0秒人物/群演数量位置姿态为准；不能为审美添加人、改变动作时序或让尚未登场角色提前出现。角色和地点参考资产用于锁定既有特征，不能靠统一美术词篡改原图。详细首帧/导演规则优先。生成成功不代表图已审阅；只把实际可见结果记为候选，保留旧批准图，由用户确认后采用。
