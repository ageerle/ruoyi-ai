# 剧情因果与节奏

用于剧本和大纲。先落实用户确认的故事年份、生活背景、人物目标与信息边界。年份与装修年代分开，旧物不代表故事发生在旧年代。
大纲只写每场的目标、触发、行动、结果和下一场原因及预算；正文只保留必要行动和对白，不混入镜头、机位、逐秒或软件操作参数。
每场新增信息或改变人物选择；合并重复反应，不用空镜、无目的独处或重复告别凑时长。把“清理→触物→回忆的行为→主动听语音”作为因果链，不拆成互不相干的摆拍。
局部修订时不新增已确认故事之外的秘密或反转；用户明确要求重构时可设计新冲突，但仍服从主线和世界观。推测需经人物求证，创作资料里的信息不能自动成为人物已知事实。
按对白、不可重叠动作与自然停顿估时，不能靠字数推出片长；用户时长优先。保留当前接口要求的输出结构。

## 故事可看性先于分镜扩写

先按用户指定类型和节奏判断开场。商业爽剧、悬疑、冒险的前段须出现可感知的异常、威胁、欲望或未解问题，使人物必须行动；不要求所有题材都用暴力、喊叫或固定秒数的钩子。人物身份、时代背景可在应对中分次交代，不先做完整问答说明会。

整集写清：主角眼前必须做到什么；什么人或条件阻止他；失败失去什么；他做了什么有代价的选择；局面因此怎样改变。因果通顺只是底线，不等于故事有张力。工艺、调查、治理的步骤只保留改变风险、关系或结果的部分，不把一个小工序拉成一集。

技术优势应在人物选择和可见结果中体现，既不能万能答案直接成功，也不能让主角全程问问题、由配角完成所有判断。工匠和普通人有经验、利益与行动能力。反转回答已建立的问题并改变力量关系，不能靠突然冒出的无关坏人、灾难或信息强行刺激。

输出前做一次删场判断：删掉这场，观众失去哪项必要理解、人物选择或情绪变化？若只少一道工序、一段重复说明或一遍确认，合并或删除。不机械固定每几十秒反转。当用户不满意故事时，先重构故事与逐句打磨对白，再投入媒体生成。

修订同时记录保留项与改动项。用户已经认可的画风、演员、服装、字幕、地点时间提示和电影光色继续沿用，不因剧情重写全部抹掉。

## 人物驱动的场景与修订

人物的身份标签不能代替性格。先看他在眼前压力下守住什么、放弃什么，以及这个选择怎样影响别人；配角也有自己的诉求和可采取的行动。冲突可来自资源、关系、职责或认知差异，不强加坏人、吵架或暴力。

每场先确认人物带着什么目标进入、遇到什么阻力、如何改变做法、离场时局面怎样变化，再写正文。变化可以是信任、风险、信息或行动机会，不要求每场反转。修订先比较场内的选择与后果，反复使用同一策略却没有新回应时合并重复节拍。进入点靠近必要事件，结束点落在改变及其反应上，保留理解所需铺垫，不延长无变化的过程。

沿项目已有状态推进前提、大纲、人物关系、场景、正文和修订；阶段结论进入现有剧本与版本记录，不额外要求用户填写知识库或改接口。返修只回到有问题的阶段，不无故推翻已定故事。具体题材、美术、时长和对白由当前项目决定。
