# 剧情因果与节奏

用于剧本和大纲。先落实用户确认的故事年份、生活背景、人物目标与信息边界。年份与装修年代分开，旧物不代表故事发生在旧年代。
大纲只写每场的目标、触发、行动、结果和下一场原因及预算；正文只保留必要行动和对白，不混入镜头、机位、逐秒或软件操作参数。
每场新增信息或改变人物选择；合并重复反应，不用空镜、无目的独处或重复告别凑时长。把“清理→触物→回忆的行为→主动听语音”作为因果链，不拆成互不相干的摆拍。
不新增已确认故事之外的秘密或反转；推测需经人物求证。软件能整理证据，不能替人物理解父亲或判断欠款。
按对白、不可重叠动作与自然停顿估时，不能靠字数推出片长；用户时长优先。保留当前接口要求的输出结构。
