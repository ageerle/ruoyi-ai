# 真实界面与证据植入

用于分镜、视频提示词和审阅。已绑定的真实照片、账页、软件页面和Excel均是原始证据，保留多个素材及其顺序、用途、时间范围。不能把多张素材压缩为第一张，也不能自动重绘文字。
真实界面已显示结果时，不虚构点击生成或加载过程。区分原图直接插入与电脑屏幕透视贴片；过肩镜头需保留肩部、电脑边框和桌面空间关系，下一镜才能切屏幕细节。
票据日期和画面设备与故事时间核对；真实截图若含不符年份的模型名、系统时间，标记为后期需处理，不伪称已经修复。AI只能识别、整理、统计，真相需人物查证。
本阶段没有授权生成视频时仅输出计划，不启动视频任务。
