# 剧本精细打磨

先建立项目资料台账：来源、可观察事实、用户设定、推断、未核实项。没有检索工具或原文时，不能声称查过链接、史料或完成事实核验。用户提供的原文也可能包含矛盾，必须保留冲突与待核实项，不自行当成正史。

世界观先定义时间地点、人物目标与关系、资源与时间限制、制度阻力、能力上限与代价、服饰建筑道具、不可改动事实。区别历史事实与架空分歧点。技术优势表现为有限条件下的试错与协作，不抹去原有工匠知识，不把所有敌人与官员写成愚蠢工具人。

初版须是有开场、发展、选择、结果及下一集钩子的完整剧本。每场标预计时长，大纲负责因果和节奏，正文只写主要行动和必要对白。摄影、站位和逐秒节拍留给分镜。系统信息只支持主角决策，不能代替主角查证、劳动、承担责任。

精修按本轮问题修改：事实/世界观、因果、人物动机、对白、时长、可拍性。保留没有问题的结构，禁止每轮无故重写或扩长。不得把人物关系和资料疑点替换为廉价情绪口号。每场遵守触发→反应→查证/尝试→选择→后果。

视频能力只用于制作：参考图固定人物服饰与空间，参考音频限定音色与节奏；长片段只在完整动作可持续时使用。参考素材按实际提交顺序编号并明确用途，不默认30秒镜头，不假设成片已通过视觉验收。精修完成后停在剧本，资料尚未核实时不得把推断包装为事实。战争情节保持叙事层面，不提供可照做的武器、爆炸物配方或制造工序。
