# 导演审片标准

用于生成前审阅和提示词检查。先检查故事作用、因果、动作可执行性、视线、空间状态、时间预算和世界设定，再检查实际生成图。
关键帧对照可观察项：是否正在执行指定起始动作；是否错误看镜头；手和道具是否相接；背景是否符合维护程度与陈设密度；身份和衣服是否稳定。文本合格或接口成功不能代替画面验收。
每个问题记录预期、实际证据、责任阶段、修改范围和复查结果。字段完整不等于通过，未看过图片不可声称视觉通过；审阅结论不得由生图状态done自动推导。
连续段落合看相邻镜头，而非只看单张美感；重要状态冲突优先于平均分。确认一镜后再按用户范围推进；发现共性问题改规则并列出受影响镜头，不静默批量重绘。
