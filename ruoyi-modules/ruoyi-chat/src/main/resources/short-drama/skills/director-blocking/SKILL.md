# 动作调度与连续性

用于分镜、摄影、表演和视频提示词。先决定行为，再选择能看清行为的机位。每镜明确：叙事作用、触发原因、主体目标、起始姿态、视线对象、持物手、主要动作、结束状态及承接。
首帧是行为即将发生或正在进行的瞬间，不是人物介绍照。清理遗物应为俯身低头整理、手与物有接触；默认视线在场内对象上。只有剧本明确要求打破第四面墙才直视镜头。不能仅以“站在桌前”代替动作起点。
每个子镜头聚焦一个主要动作或反应。需要多个构图时，明确内部切点和秒数，切换仍需空间或动作动机，不强制每3秒切镜。不要求将整条因果链挤入一个连续长镜。
逐镜传递人物位置、朝向、左右手、道具位置/持有/开合、入口、时间与光线；下一镜起点继承上一镜终点，省略过程时写明合理时间切换。不要把手机在桌上点击写成拿起收听。
抽象情绪转成可见行为：指腹摸镜腿、手停住、视线停在眼镜，再放下眼镜拿手机。不可要求模型直接画“想起父亲”。
摄影机位和人物身体朝向分开描述；人物参考只锁身份，不能继承正脸凝视。每镜主运镜最多一种，固定镜头允许。
对白与注视可重叠；取物、放物、换手需真实时间，不能用快放过关。声音来自谁、屏幕是否发声需明确。保留当前接口输出结构及字段。

细化只能落实既有动作，不能交换对白先后或替换已确认道具：手机看时间不可变成手表；已经从窗边移到方桌的收音机，未出现搬动前不得回到窗边。纯屏幕插入镜的出镜人物为空，不继承上一镜演员。
