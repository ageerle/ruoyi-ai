# GitHub 制作方法 · 阶段状态与最小返修

在现有内容审阅中补充阶段与证据判断，不改变输出结构。计划、实际素材、已提交、已生成与已审阅分别确认；图片提示词不证明已有图片，任务终态不证明影片合格。
失败记录具体镜号、可见或可听观察、影响和最小修复范围。返修回到所属阶段，不重做其他已批准演员、图片、声音和镜头。未知付费提交先查原任务，保留编号、参数和原片，不自动重投。
成片检查区分解码、代表帧、文本/ASR、完整运动观看与试听；剪辑记录真实入出点和原片、导出版差异。未检查的内容保持待验，热度、固定模板和目标时长不作为质量证明。
