# 场景与人物视觉锁定

用于人物、场景和镜头图片。分别锁定故事年份、建筑装修风格、维护程度、陈设密度；服装与设备服从项目设定。禁止把年代感、情感、父亲遗物自动翻译成破败、霉斑、灰尘、垃圾或废弃空间。
所属项目世界观只作为年代、材料可获得性和发展阶段的约束，不是待画物件清单。本张资产描述决定当前可见事物、规模与生长状态；后续计划、未来装备和未完成的建设不提前出现，多年代故事不混用其他时点的服装与材料。
前现代场景没有已引进的剧情依据时，不添加塑料薄膜顶、塑料育苗盘、现代工业玻璃棚、洋装或西式翻领衬衫。温棚、苗床、作物使用当前描述实际给定的材料、种类与阶段，不将幼苗、初次试种或短期观察画成成熟稻穗、密集丰收田。
贫困和建设初期服从当前描述的小规模、低陈设密度与未完工程，不因“电影级”放大成繁华都市、巨大湖面、豪华铺装或竣工城防；节制不等于一律加破败污损。场景构图呈现实际空间，无依据的地名牌匾、城名字样和招牌不得凭空创造，精确文字留给后期。
场景参考为无人物的空间基准图：明确入口、窗、工作台、主要家具相对位置，光源可解释；陈设分区有序，留出人物活动区。只保留少量有叙事作用的可移动物，避免杂物淹没主角。
人物设定图用于身份和服装，正面视图属于设定用途；叙事首帧必须重新按本镜动作、视线和机位构图，不复制设定图姿势。先遵守用户确认的身份，不能借重新生图换脸、换年龄、换衣服。
上述连续性锁默认适用于已批准素材。请求明确标记为“身份绑定的修订候选”时，参考只提供脸部身份或非人主体的核心辨识点；允许按本轮明确要求纠正材质、服装裁片或指定结构，不沿用被拒参考的对应缺陷。未指定项继续保持，候选经人工选择后才纳入批准连续性。
背景参考锁定建筑与家具，移动道具和门灯状态以本镜为准。手接触的物体应看得见且数量合理。场景不能被误生成人物合影。
图片只画当前时刻，不提前出现后续发现的账本或已完成动作。说明构图焦点和允许出现的物件，不能只堆砌“电影级、悲伤、怀旧”。
国风三维动画应有可见的风格化CG雕塑体块、清晰体面与受控色面，角色发束和布景材质经过设计；不能把仿真人数字人、写真肤质或真人棚拍等同于动画。身份比例与年龄保持，材质风格不靠换脸或夸大五官实现。
