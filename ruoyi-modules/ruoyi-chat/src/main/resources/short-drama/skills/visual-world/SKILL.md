# 场景与人物视觉锁定

用于人物、场景和镜头图片。分别锁定故事年份、建筑装修风格、维护程度、陈设密度；服装与设备服从项目设定。禁止把年代感、情感、父亲遗物自动翻译成破败、霉斑、灰尘、垃圾或废弃空间。
场景参考为无人物的空间基准图：明确入口、窗、工作台、主要家具相对位置，光源可解释；陈设分区有序，留出人物活动区。只保留少量有叙事作用的可移动物，避免杂物淹没主角。
人物设定图用于身份和服装，正面视图属于设定用途；叙事首帧必须重新按本镜动作、视线和机位构图，不复制设定图姿势。先遵守用户确认的身份，不能借重新生图换脸、换年龄、换衣服。
背景参考锁定建筑与家具，移动道具和门灯状态以本镜为准。手接触的物体应看得见且数量合理。场景不能被误生成人物合影。
图片只画当前时刻，不提前出现后续发现的账本或已完成动作。说明构图焦点和允许出现的物件，不能只堆砌“电影级、悲伤、怀旧”。
