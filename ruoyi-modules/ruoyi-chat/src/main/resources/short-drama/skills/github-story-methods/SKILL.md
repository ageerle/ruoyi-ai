# GitHub 编剧方法 · 改编证据与叙事承诺

仅补充剧本和故事阶段的方法，不引入独立摄影格式。原著改编的关键保留和删改有来源依据，未读部分注明；已有剧本沿真实分集边界继续，不要求重建平行文档。按当前题材、集数和时长组织主角需求、阻力、选择和后果。
每集的问题有铺垫并在人物行动中推进，结尾变化带来下一集继续的原因。人物档案区分身份、关系和知情边界，资产清单从故事中汇总。对白按人物需求和语气修订，不机械套固定反转间隔、四层反派或五十至一百集结构。时长按对白与行动估算，估算只是制作参考。
