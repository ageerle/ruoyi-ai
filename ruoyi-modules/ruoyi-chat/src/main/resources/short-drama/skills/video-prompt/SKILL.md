# 单镜视频提示词制作与审阅

默认随分镜细化和视频提交加载。它是项目业务能力，不需要用户每次重新调用工具或粘贴模板。生成任务与最终摄影镜头分别设计：默认单镜保持连续，明确使用 multi_shot 的同场表演段可按信息变化内部切镜。段长服从真实内容与当前模型限制，不照抄其他平台镜长或模型专用 @ 图片语法。

视频秒数默认未指定。duration 和 timing 是制作估算，不能自动作为上游 duration/seconds 参数；只有用户明确设置 video_seconds 才传秒数。自然导演稿完整保留剧情、原对白、动作结果和交镜，不按估算秒数删减、压缩或提前收尾。留空时不写固定目标秒数，不把估算包装成已指定时长；用户指定值及模型自动时长选项由实际模型处理。

## 输入权威与边界

已确认的剧本原文、世界观、人物形象、场景和起止状态为依据。首帧是可选参考，不是生成视频的前置条件，不默认为批量视频额外生成首帧。选择使用首帧时才审阅实际画面并从该状态展开；没有首帧或明确关闭首帧参考时，使用已批准的角色、场景、道具与起始构图规划，不假称规划是已审阅图片。保持精致服装及穿越元素的逐角色差异；禁止把全体角色统一成粗布衣服。参考图绑定由实际视频模型适配器处理，提示词不假造 @image 标签、文件名或不存在的绑定。年龄性别标签必须与具名角色一一对应；不能只写“年轻男子”而让两个同龄角色混淆。

只描述本镜实际出场、发声或互动的人物与元素。未出场的角色、精灵与投影直接省略，不把“Codex不出现”等排除句作为每镜通用负面约束；下一镜完整起始画面留在连续性资料中，不复制进本镜video_prompt。

一个摄影镜头一个主导运动。连续表演段内的切镜由动作、视线或新信息触发；禁止靠无因果切镜、地点跳变或新增动作填长时段。CG、精灵、透明投影只能在本镜世界观和出镜名单允许时出现；存在实体形象的智能体不能随意退化成画外声，也不能变成所有人可见的全知工具。面板保留透景和光源关系，复杂文字/账目走后期叠加，不要求模型逐字生成。

## 镜间衔接与声音连续

先定义相邻镜头的接点：动作在哪一拍交接、人物视线指向谁、轴线是否一致、哪句声音或哪种环境底继续。对白可在听者、手部或物件画面上延续，下一场声音可在画面切换前进入。提示词写出意图，剪辑表另记实际执行；只写J-cut/L-cut名称不算已完成。

按叙事选转场：同场对话与动作通常在接点直接切；时间流逝、气氛转换或适宜构图可短叠化。用户要求平滑过渡时可从0.2—0.4秒试作，仍核对重影与台词完整，不给每一切机械加0.3秒叠化。错误站位、衣装或动作不能用特效遮掩。场景地点提示、字幕和已认可的美术与演员不因新剪辑策略丢失。

## 一个属性，连续导演描述

把人物目的落到行为上：想护住谁、阻止什么或向谁争取什么，应从原文和眼前刺激得到依据。先写行动受到怎样的回应，再写人物如何调整；少量可见动作承载这些变化，不用连续表情词和姿势指令把演员变成木偶。听者继续承担当前行动，对白、呼吸与受力可以并行。段内切镜落在关注点变化、动作接触或真实反应上，保持原话与声源；单纯缓推、整齐站姿与漂亮布景不能替代人物压力。

先依据对白实读/录音与必要事件确定时长，再写节拍，不能先选长时长再用微动作填满。眨眼、转头、看服装和摄影运动一般与对白并行，不重复计入action_seconds；服装细节在剧情表演中呈现。约30分钟等全剧目标是故事预算，内容不足应调整故事与场次，不能逐镜拉长停顿。

timing记录对白、动作和必要停顿的估算；pacing_note可说明实际事件或情绪变化。估时有不确定性，也可能包含同时发生的动作，不把算出的秒数当作硬下限或精确总和。片段结束在动作结果和必要反应完成处，允许自然的剪辑余量，不要求最短整数秒或固定尾留时间。

实战镜头按“动作发起→命中/受阻→可见后果→关键反应”写成一条主因果链。上一步未出现可见结果时不推进下一步，结果落地后不继续空等；群像其他人物只承担反应层，不能在一个4—15秒单镜内同时塞入多条独立战术事件。

提交付费视频前留时长依据（对白秒数、独占动作、必要停顿、并行关系）并进行一次节拍预演。已有录音优先用实测；估算注明语速及不确定性。生成后复核实片台词区间与有效事件，若出现无意义空等，先调整剪辑/节拍并保存候选，不把结构校验通过当作成片通过。

工作台只展示和编辑 video_prompt，不另设时间预算面板。摄影规则、表演指导、承接和本镜原台词的可拍内容全部融入这里；结构化原文、角色/道具绑定、起止状态和 timing 保留为制作元数据，不能为了界面简化清除。

先用一句话建立本镜当前空间和必要站位，再顺着人物动作写。需要段内切镜时可用“镜头1：”“镜头2：”，由新信息、视线或动作引导切换；单镜直接写成自然段。描写画面如何发生，不写“揭示身份”“完成转场”“扭转局面”作为动作，不输出0-2秒、2-5秒的调度清单。时长、对白语速、独占动作和必要停顿在 timing 与制作时间线中核对，制作估算仅供节奏审阅。

镜头里要能读出：机位看到的前后左右关系；人物向谁看、如何移重心或递物；对方收到动作/话语后的反应；机位为何跟随、切换或停住；既有光源如何照到衣料和物品；环境声来自哪里；交镜时手、视线、人物和物品仍在什么状态。把这些信息放在它们发生的地方，不在末尾重复罗列全部约束。

精细程度来自同一动作中的可见细节。开头明确前景遮挡、中景主体与背景参照，让身体、手、持物和视线有真实落点；刺激出现后写出重心、肩颈、眼神与手指如何改变，以及听者如何接住这个变化。镜头移动随这些变化而发生，光源和材质写在动作经过的位置，声音分清远近和被门墙遮挡后的质感。短镜加深同时发生的画面信息，不追加多条事件、慢动作或停顿来凑篇幅。避免“他很紧张”“镜头展示精美服装”“两人交谈”等概括，也不为所有镜头复制资产说明或一套反应动作。

原对白逐字嵌入对应动作，写成“角色低声问「原话」，听者抬眼……”并保留发言人和顺序。说话者嘴部动作属于本人，听者只做反应；画外、心声、录音明确声源，不驱动画内听者口型。无对白的镜头写明环境声。必要局部限制随具体事件说明，避免给每镜复制整部剧的负面词。

写法示例：

> 客栈堂内，掌柜站在柜台后，来客靠着画面右侧门框，两人之间隔一段空桌面；前景左下是柜台角，后方布帘垂在掌柜右肩外。平视中景固定在柜台外侧，桌沿把两人的手和身体隔开，门外午后日光从右侧斜照来客的脸，柜内较暗，但墙面反射保留掌柜眼睛。掌柜把茶盏推到桌沿，杯底轻擦木面，抬眼问「喝点什么？」说话时手指仍搭在杯边，肩膀没有跟着前倾。来客没有伸手，目光从茶盏移过掌柜肩头，落到布帘的下角，撑门框的手指微微收紧；掌柜看见他的眼神越过自己，也停住推杯的手，侧耳听后边动静。机位沿来客的视线轻移到帘边，前景保留掌柜半边肩，焦点从杯口转到晃动的帘角，动作不跳轴。街上脚步声隔着门口传入，杯底停下的轻响在近处，帘后只留衣料摩擦声。画面停在帘角露出一线暗缝、掌柜的手还压着茶盏的状态，以尚未看清的帘后动静交镜。

示例只演示写法，人物、台词、场景和时长必须从当前剧本及资产取得，不复用示例剧情。

## 生产守卫

涉及搬运、到位、触发、效果和余波时，逐段明确当前动作阶段。物件在运输或等待中不提前发生下一阶段的声光效果；触发的可见动作、特效起点、声音时点与人物反应须对应。出现冲击后果时，先建立被作用物件的来源、外形与持握状态，再表现它如何受力、变形或落地，不在结果镜凭空增加大物件。效果镜须留下实际可见的完整动作，不能在闪光、喷烟或受击刚开始时切走，再用声响代替缺失画面。此规则按当前剧情应用，不给所有题材套同一段爆炸或禁用词。

场面压力来自空间障碍、真实受力、角色目标与错落的群体反应。建立内外、上下、进退路线及物件与人的相对尺寸；群演沿自己能看见或听见的刺激先后反应，避免整齐站位、同时摆姿和轻松完成重体力动作。漂亮大全景不能替代空间逻辑、威胁和人物代价。成片同时查图、声音与剪辑落点，字段完整或任务完成不算视听通过。

video_prompt 审阅看可执行动作、摄影光色、声音、原话与发言人完整，默认接受自然导演描述，不要求八标题或显式秒段。已有时间分段稿保留可编辑；若主动使用秒段，仍检查覆盖、重叠和空洞。没有显式秒段不代表可以忽略 timing 的内容预算。不设最少字数，不奖励冗长。程序结构检查只是第一层，最终仍要对照实际使用的参考、人物资产、声音预算和生成视频逐镜审阅；未使用首帧不构成缺项。

模型输出的动作、声音、预算、对白与摄影缺项记录为审阅建议，不因词法匹配、估算偏差或标题缺失自动重写并判定失败。只有无法解析的输出、空白生成指令或不可用的资产引用需要修复。保留用户原话与可编辑权；结构通过不等于成片验收。

## 审阅建议与保存

按剧情内容和节奏自然分段，镜数允许合理波动。时长、对白语速、停顿、接镜描述和状态锚点都是制作参考；估算偏差、文字不同或辅助字段缺项只作审阅建议，不作为拒绝保存或自动重写的条件。不按固定镜数、最短整数秒、总时长容差或逐字相等判定创作失败。保留原剧情与对白，缺少依据的细节留待审阅，不为满足检查增加事件。
