# ZenStory · 分阶段制作流程

## 阶段路由

先识别输入是点子、原著、完整剧本、资产、分镜还是已有素材，读取项目真实状态，从缺失或有问题的阶段继续。创作事实使用项目已有数据库和版本记录，不建立与它并行的一套“真相”文件。

## 制作流程

原著分析和分集地图按需要建立；有完整剧本时直接进入资产与视觉决策。剧本负责事件、人物选择、对白和基调，视觉负责身份、造型、场景和道具状态，分镜负责观众信息、空间、切点和动作承接，提示词负责模型可执行的表演与声音。
每次交接写清已确定事实、尚待确认内容、实际素材和本次改动范围。人物主身份与服装版本分开，声音归属人物主身份，镜头持物和视线属于逐镜状态。图片计划与真实文件、生成完成与审阅通过各有状态。
媒体任务沿用项目当前模型、资产及已有提交恢复机制，保存原任务编号与参数。未知结果先查询同一次提交，不能因界面超时重复付费生成。
剪辑只使用真实生成素材，记录可用区间、入出点和取舍，字幕来自原对白，声音按真实时间线处理。保留原片及导出版，区分检查脚本、抽帧、ASR、全片运动观看和试听的证据。

## 返修与交付

返修回到问题所属阶段，保留其余已确认内容。检查镜间与跨集事实是否一致，再交付当前剧本、视觉、分镜、实际提示词、素材与检查记录；不得用一个目标时长或任务终态宣称已成片验收。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
