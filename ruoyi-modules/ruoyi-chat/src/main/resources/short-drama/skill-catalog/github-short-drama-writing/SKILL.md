# 微短剧 · 选题、人物与分集

## 选题与人物

从已确认故事、受众和基调确定叙事承诺。先明确主角想得到什么、遇到何种阻力、失败损失和有代价的选择；角色身份、动机、关系与知情边界从故事中建立。

## 分集方法

总集数和单集长度来自项目，不能默认五十至一百集。大纲交代每集起因、人物行动、局面变化和下一集的问题。悬疑、关系、情绪、危机和信息都可构成钩子，选择能被后文兑现的一种，不机械每集强行打脸。
阻力可来自职责、利益、认知或现实条件，不要求所有题材采用四层反派。人物以不同策略争取自己的目标；对手有回应与能力，主角优势要在行动和后果中体现。
单集正文让对白、行动和回应推动关系，压缩重复介绍和无变化工序。开场尽快兑现该集要解决的问题，保留理解所需铺垫；结尾落在真实变化及其影响上。

## 修订与出海

检查承诺是否兑现、铺垫是否被看见、人物是否突然知道新事实、对白是否符合当时意图。出海改编核对文化背景、人物关系和口语，而非只翻译台词；具体平台要求另查当前来源。局部改稿保留其他已批准情节和演员版本。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。

## 场景进出衔接

开门只改变通行条件，不等于人物已经进屋或出屋。涉及进出时，正文写清人物原在门的哪一侧、跨过门口到哪里，以及到位后才发生的事；导演阶段再落实机位和门扇方向。后续离场由它自己的剧情原因触发，不提前混入入场动作。局部返修保持原片其他对白、动作和场序，正文按标题、动作、逐句对白分段留空行；未获当前用户指定不补目标时长。

## 已定稿剧本交给分镜

用户只要求重写分镜时，把当前确认的完整剧本作为唯一剧情与对白依据，不触发再次改编或重写台词。按场保留事件顺序、角色知识、衣装和关键物件变化；旧候选分镜及参考案例只可用于发现问题，不能覆盖当前原文。编剧风格负责故事与台词，镜头格式和运镜由默认导演规范及选中的唯一导演风格处理。
