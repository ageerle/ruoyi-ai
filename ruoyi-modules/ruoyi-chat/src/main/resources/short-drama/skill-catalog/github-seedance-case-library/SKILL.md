# Seedance · 案例与技能导航

## 案例选用

先按当前题材、观众、画风、镜头目的和真实素材选少量案例。剧情、广告、恐怖、宠物、旅行和风格展示的成功条件不同，不能把广告开场或短视频钩子强加给所有短剧。

## 阅读方法

记录原始发布者、公开来源、日期、标注模型、实际媒体与提示词是否匹配。没有成片或提示词的记录只作灵感，不算同配置复测；热度不能代替角色、运动和声音质量。
提取一个可检验的方法：参考图控制什么、镜头如何揭示信息、动作怎样抵达结果、声桥有什么作用。改写时换成当前角色、空间、时长和声源，不沿用别人的剧情和参数。
比较候选时明确计划、素材就绪、已提交、已生成与已审阅状态；有后期修整时记录原片和导出版差异。任何重新生成仍需实际授权，查阅资料不会自动消耗媒体额度。

## 使用边界

本条归导演风格，选中后从案例方法中提炼适用于当前镜头的运镜、表演与承接要求，不整段套用案例。示例图、视频和第三方帖子各有权利范围；代码仓库许可不等于案例媒体可再发布。需要复测时按现有制作流程另行记录证据。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
