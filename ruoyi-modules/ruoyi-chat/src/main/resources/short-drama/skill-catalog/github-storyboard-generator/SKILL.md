# 故事转分镜 · 资产与段落交接

## 分镜输入

读取当前剧本、资产和制作方向，先确认本集事件与人物关系。核心冲突和情绪变化来自现有故事；已有分镜时只处理用户要求的镜头，不重写整部作品。

## 段落规划

给每段一个观众必须看见的变化，把出现人物、空间关系、关键道具与声源落实到该段。以用户已定时长及当前模型真实能力规划，不固定五集、十五秒、镜数或反转公式。
为角色、地点和物件保留稳定引用，衣装及受损等状态单独记录。每镜附实际素材用途；已有角色、场景与道具参考可直接用于视频，不为了流程完整默认批量生成首帧。
段内按动作与反应安排景别和机位，摄影变化服务当前信息；段间明确入点、出点、人物朝向、持物和道具结果。换时换地应有剧情依据并重新建立空间，连续事件则沿前镜末态展开。
导演正文保持连续描述和原对白声源，声音可通过对话延续、动作拟音或环境底声完成接续。分镜计划与最终剪辑镜头可以不同，原始生成段和实际剪辑区间都保留。

## 交接审阅

核对故事有无漏段、角色与关键物是否真实绑定、镜间动作能否接上，再交给现有细化与内容审阅流程。发现问题返回对应上游决定，不靠更多摄影形容词掩盖。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
