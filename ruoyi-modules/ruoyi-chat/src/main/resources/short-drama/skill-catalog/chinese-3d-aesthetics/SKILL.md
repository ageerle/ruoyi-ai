# 国风三维资产审美

适用于国风三维动画；服饰和建筑按当前项目年代、地域、身份、年龄与发展阶段制作，不默认所有项目都是明代。现代序幕仍采用现代服饰与空间形制。

先建立人物的可辨轮廓、眉骨鼻梁颧颌体积与年龄，再定主辅点睛色和材质。人物拥有不同脸形、体型、发束和衣纹受力，眼睛明亮但不过大，受控皮肤散射，不做蜡像、网红尖下巴或真人写真皮肤。角色身份参照是同一身份，构图按当前资产描述明确选择单幅全身或多视角，不把参照布局套入实际首帧。

衣服写清帽、领、叠襟、袖、腰带、下摆、鞋和纹样的结构及身份依据。棉麻漫反射，绸用窄柔高光，皮革具厚度和局部磨损，铁冷灰、铜暖褐，木材按构造和适度纹理表达。贫穷是普通材料、局部修补、少量功能陈设，不是遍身泥污破洞；富裕不等于满屏金雕。

无人物空间参照建立人尺度、出入口、通行区、前中后景、门窗桌椅固定关系、功能器物和可信光向。保持当前建筑规模和成长阶段，不把贫县改成宫殿，不让早期苗床成为成熟丰收。物品接合和支撑落地，器形按用途，不新增虚构武器制造配方。

实际首帧严格遵守当前0秒演员、匿名群演人数、位置、姿态、手中物、CG比例及当前镜头光色；既有批准参考锁身份和建筑几何，不能因审美改脸、镜像、换装、加人或提前演结果。新候选只有实际逐张审阅并选用后才纳入连续性。
