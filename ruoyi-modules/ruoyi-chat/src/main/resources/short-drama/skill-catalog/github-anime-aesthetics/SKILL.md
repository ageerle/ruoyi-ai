# 动漫动作 · 轮廓与动势

## 视觉决定

角色比例、五官、头发、衣装和色板以当前故事及已批准形象为准，不套通用少年脸或统一大眼。动作关键姿态轮廓明确、重心可信，服饰和持物在转身、跨步与接触时保持空间关系。
夸张形变、速度线和光效仅在所选动漫风格需要时使用，强调动作方向、接触和后果，不能掩盖命中或让人物瞬移。情绪表演按角色意图安排眼神和姿态；静止与运动段保持同一光色和线条，真实效果由候选画面与成片检查确定。
