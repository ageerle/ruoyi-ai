# Seedance · 表演、摄影与声音

## 适用范围

用于人物对话、情绪转折、连续行动和多段接续。先读实际剧本、角色声音、空间、道具状态及本镜起止构图；观察段和产品展示保留用户指定表达，不硬塞冲突。

## 导演方法

先明确观众在此段应该发现什么，人物试图得到什么、压住什么，以及哪个可见变化使局面不同。把这些判断落实为视线、手物接触、停顿、距离或声音，不将内部分析术语原样塞进生成正文。
选择一条服务事件的主摄影策略，说明起点、速度、主体关系与落点。动作发生前让空间关系可读；机位改变不能造成角色换姿态或道具回退。短段不叠加相互冲突的升降、绕行、推近和抖动。
光源应属于当前空间，明确亮暗面和必要材质变化。身份参考负责外观，动作视频负责运动，声音参考负责指定角色的音色；参考职责分开，避免连同别人的演员、房间或台词一起继承。
对白逐句保留原话和声源，让听者的回应接住前一句。画外声、旁白与画内说话分开；音色一致、内容正确、声音自然和口型同步分别核对。环境声建立空间，拟音对应接触与受力，音乐服务段落变化。

## 接续与返修

下一段继承上一段的实际末态和已确认切点，不重新演一遍已完成动作。记录真实画面与计划的差异，先定位失败的镜头、参考职责或声源，再修最小单元。

## 媒体提示词

从本镜确认的身份、空间、构图与动作状态展开，将主要事件、对手回应、摄影落点、实际光源和原对白声源融成连续描述。听者和画外声保持准确归属，音效与接触先后对应；结尾留下清楚可衔接的动作状态。参考只控制分配给它的身份、运动或音色。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。

## 门口与空间转换

涉及进出门时，分别确定摄影机所在一侧、人物起点、门扇开合与铰链侧、跨门路线和抵达位置。门可内开或外开，按当前资产与剧情确定；门扇运动不代表人的行进方向。有锁或门闩时先解除，再移动门扇，钥匙和锁的去向延续到下一镜。
让观众看见人物从起始一侧经过门口到目标一侧，或在能核对位置的动作匹配点切镜；不能只写“推门”就切到人物已在房间深处。入场完成后再取物、检查或交谈；后续离场单独保留它的触发与路线。


## 进出动作审片

入场和离场对照前镜末态、开锁、门扇运动、跨门和抵达的完整运动及后镜起点。判断依据是人从哪一侧走到哪一侧，不能只凭门向内或向外开判断。抽一帧或结构检查只支持局部结论；重要跨门动作需连续播放或密集帧核查，记录未核查的运动与声音范围。返修保留其他通过素材，剪辑验证切口没有截断原对白或提前插入离场。

## 固定的可读导演稿格式

新生成和用户要求重写的 video_prompt 使用以下三部分，部分之间及各编号镜头之间空一行。它是可阅读的导演稿，不是逐秒表格；不要套用参考例子的人物、事件、画风或镜头数量。

【起始构图】写本段开始时实际空间、可见人物的身份与必要衣装、相对位置、朝向、姿态、持物和已经发生的动作状态。只有本次确实采用并审阅了首帧，才改用【首帧实况】并以实图为准。角色/场景母图不是已审阅首帧；不能虚构首帧已批准。

镜头1：从起始状态连续展开本段事件，写清景别、机位和一条主要运镜；按动作发起、接触或受阻、可见结果、对手反应推进。原对白逐句注明谁说、对谁说及画内/画外/内心声，安排在真实动作之间。需要有动机的内部切镜时另起镜头2、镜头3；单镜也保留镜头1，不为了格式硬添切镜。同一段只发生同一时空内的连续事件，跨时空另建生成段并记录接点。

当前空间为……。收束段交代此刻的光向、必要材质、环境声与动作声、说话者口型和画外声规则，以及最后确实留在画面中的姿势、位置、手中物和切出点。已经在编号镜头写清的内容不再抄写；只补保证声音与末态可执行的要求。下一段剧情放在 continuity，不提前演出。每部分都应是本段具体内容，不能用通用摄影前缀或几句摘要代替。

原剧情与原对白不因格式调整而删改；时长估算独立存入 timing，正文不列0—2秒等清单。旧人工稿只读、复制或展示时不自动改写；新稿保留真实换行，编辑器不靠视觉折行代替持久段落。

## 资产版本与原文角色核对

分镜前读取本版制作要求并列出实际允许的角色形象索引与场景名。按当前原文时点选择衣装，不从形象的排序、新旧、名称相似或视觉精美程度推定已获批准。标为候选、重设计或待确认的版本只有本版明确选用才绑定；主角衣装改变须有原文依据，不能提前选到后期受伤形象。

characters与present_characters只填写目录里存在的精确姓名，appearance填写其真实索引或精确阶段名；不用“标准形象”等自造通称猜索引。原文中未登记的一次性职业角色仍保留全部对白和动作，作为有明确位置与声源的匿名群演描述，不假造角色ID，不借用另一个角色的脸或声音。

## 原文时日、逐镜形象与物理状态

场次标题和当前原文决定昼夜、季节、天气及前后时间；“接上场”沿已发生状态继承。场景母图中的白天、雨雪或固定灯色只提供空间参考，不能覆盖本场冬夜、雨停或暮色。细化必须收到原场次上下文，不能只收到去掉场头的动作切片。

角色形象由本镜 characters.appearance 绑定决定；细化只传该镜已选形象，不把同一角色所有历史、未来衣装或重设计候选一起标作已确认。旧资产文字中的历史场号不能覆盖当前剧本。玉佩交出、衣袖破裂、门闩落定、炮车位置等改变一旦发生，后镜继承，不因另一张参考图重新完整、换装或复位。参考母图与当前剧情不符时保留原图、按用途限制引用，记录冲突；不默改原文或生成新媒体。

按原文顺序核对对白与动作，含没有引号的“角色（内心声，嘴唇不动）：原话”。允许将一句原话分在动作前后，但说话人、字句和顺序不能变；旁人在场不等于由旁人代说。只提到某人不等于该人在画内，已经完成的递物、落座或敲查不从头重复。带修理、运粮或练路的时间省略须明确剪辑，不能把物品瞬间修好，也不能要求短段演完数次完整往返。

交付前按原剧本建立逐场原文覆盖表，并逐镜核对实际导演稿：空行、起始构图、编号镜头、当前空间为开头的收束、原话声源、当前衣装与末态。程序检查辅助发现漏项，完整文本审阅负责动作因果与身份归属；实际视频另做运动和声音验收。
