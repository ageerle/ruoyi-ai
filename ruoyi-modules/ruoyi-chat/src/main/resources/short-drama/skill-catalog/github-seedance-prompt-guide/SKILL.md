# Seedance · 多模态提示词

## 输入整理

区分文字构图规划、已有图片、已审阅图片、动作参考视频与角色声音样本。逐项列出实际素材、顺序、角色和用途，不把图片提示词当成已有图片。

## 编写方法

先写本镜身份和起始空间，再按刺激、行动、受力结果与反应推进。图生路径不重复整套外观手册，但保留当前人数、姿态、手持物、接触和景别所需信息；没有图片时用本镜必要视觉事实建立起点。
参考图固定角色、造型或地点；视频参考只迁移用户选定的运镜、动作或节奏；音频参考明确负责音色或音乐节拍。上游 @图片、@material 等语法不直接作为本系统协议，实际编号由供应商适配器生成。
摄影用景别、机位、运动速度和末端位置交代，避免只写电影感。复杂运动先保证主事件与空间可读，再增加有理由的摄影变化。镜尾写到动作结果，留出接续所需姿态和道具状态。
将分辨率、画幅、可选秒数放在参数里，将对白与独占动作预算放在 timing，最终正文为自然段。模型版本、参考数量、输入上限和延长能力从当前目录或官方接口核对，不用仓库旧数值覆盖项目。

## 审阅

检查素材用途和正文是否矛盾、人数与声源是否正确、动作能否从起点抵达终点。生成后另查真实运动与声音，文案检查不能证明视频已通过。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
