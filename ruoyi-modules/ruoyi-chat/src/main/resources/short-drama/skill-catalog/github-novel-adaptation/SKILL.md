# 说好 · 小说改编与制作资料

## 改编范围

以用户提供的原著、章节和已确认取舍为依据。先确认当前需要大纲、角色、剧本还是分镜；已有材料可从对应阶段进入，不补造无用的上游文档。

## 改编方法

长原著按真实章节边界建立索引，记录读到的范围、重要人物、因果事件和改编保留点。关键改动保留来源场次或章节依据；未读段落保持待核对，不能凭书名补情节。
大纲先确定主线目标、障碍、选择和后果，人物关系与场景职责随之确定。每集留下本集变化和下一集继续的原因；悬念需要在后续事件兑现，不将反转间隔、角色档上限或三幕结构设成所有作品的硬门槛。
人物设定区分身份、行为、关系、外观和声音；场景与道具区分固定形态与当时状态。资产清单从已写故事汇总，反向核对没有遗漏剧情关键物，不为丰富画面擅自增添物件。
剧本用动作与对白交替表现人物的决定，不把梗概直接扩成讲解词。对白按人物需求、知情边界和语气精修；尚无录音时将语速估算标明，必要行动与停顿另计，不能只按字数推断片长。

## 项目交接

保留现有剧本、角色、地点和道具记录作为事实源，原著索引只作辅助。分镜只落实已接受的故事和资产决定，发现上游矛盾先回到对应阶段修订。制作资料按实际集数和镜号关联，不照搬来源的文件名或 JSON schema。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
