# 漫画运动 · 画面层级与连续性

## 视觉决定

从已批准漫画造型与当前画风建立稳定人物、地点和道具。线条粗细、色块、轮廓和必要纹理统一，前景遮挡、中景人物、背景参照分层，运动和景别切换不让脸型衣装漂移。
设计可用于有限动画的视线、手部、呼吸和轮廓变化，但真正改变剧情的行动仍需看清起因和结果。漫画文字、对白气泡和字幕按用户决定保留或后期处理，不让生成模型虚构文字。漫画格不是必须的首帧形式，具体裁幅和镜头来自当前分镜。

## 资产审阅

先比较角色身份、服装、道具与场景的既有批准版本，再检查形体、材料、色彩和各景别可读性。新图作为候选，用户选用前保留原媒体；不因技能升级批量重画。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
