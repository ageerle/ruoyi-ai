# 故事张力、人物台词与声画衔接

触发：用户反馈“逻辑通顺但无聊”“台词像AI朗读”“镜头跳跃”。这是剧本和执行的缺陷，不是只要提高画质或加转场特效就能解决。

## 2026-10-02参考复查

通过Edge重新打开[《窃丹-卖龙》第二集](https://www.liblib.tv/detail/952907748bc84fae80a12f0a07646140)，读取公开故事板2-1第一、第二场，核对成片0秒及约25秒画面。研究范围仅上述内容及先前已留档候选，不宣称全片已听审，也没有证据证明作者统一使用0.3秒叠化。

开场人物已经处于被控制的危险关系；求饶、施压、躲避同时发生。随后重要物件把危险转成“究竟是什么、谁在说谎”的疑问；下一场通过异常后果重估人物身份与力量关系。暴力不是可以照抄的配方，真正可迁移的是观众的问题随着证据升级。

分镜文本明确让一句话跨到物件、听者反应和相邻镜继续；手部入画、遮挡、看向画外的人物引导摄影。方言与人物关系和态度相连，人物在试探、抵赖、讥讽，不在互相讲解设定。不要复制其具体角色、台词、暴力动作或美术。

## 上一版本的反例

本地E01约五分钟，主角问县情、问故障、安排修水、重复试验、确认通水。虽然因果成立，但观看动机弱，技术工序过多，主角缺乏有压力的选择，台词多为完整解释句。现有字幕、人物场景审美和地点提示已获用户认可，必须保留。

上一版只做接触表与ASR，不能由此推断台词听感自然。并发生成后多数直接拼接，也没有实际完成设计中的声桥。生成任务完成和文件可播放不是电影叙事或声音通过。

## 生成前先完成的写作工作

1. 写整集核心矛盾、主角眼前目标、失败代价和一次改变局面的选择。每个场次说明它让观众多知道什么、担心什么，或改变了哪个人物的选择。没有这些作用的工序压缩。
2. 按用户的类型要求设计开场。爽剧、悬疑可从危机中进入，身份与背景在行动中交代；不是所有题材必须打斗或固定十秒反转。
3. 写作模型先做结构稿，再根据具体批注精修对白。提示词必须给角色意图、利益和信息边界，不只要求“去AI味、电影感、自然”。使用项目当前确认的真实型号，保存原输出与修订理由。
4. 每句问：谁要从谁那里得到什么？对方上一句话怎样改变这句？四个角色是否可以交换台词仍成立？删概念口号、工作汇报与无对象的主题总结，保留具体回应、回避、打断和有语境的幽默。
5. 文本与声音分开验收。分角色记录对话对象、目的、重音和停顿。经授权的稳定音色参考进入实际引用，不能只在提示词写角色名就声称锁音色。ASR只能辅助字幕，试听才可能判断朗读腔、重音与情绪。

## 每个剪辑接点都要有设计

为相邻片段写一行：前镜出点动作/视线 → 后镜入点；保留哪段声尾或提前哪段声音；是否需要叠化及为何需要；地点时间提示是否出现。

- 连续动作：切在动作进行中，下一镜从对应动作状态接，不重复起势。左右关系和手中物品保持。
- 对话：一人的声音可以落在听者或物件画面上；不要所有人都说完、静默、再切给下一人。
- 换场：下一场环境或一句话可先进入，帮助建立预期；音乐不能替代空间交代。
- 时间/气氛变化：按需要使用约0.2—0.4秒叠化，实际看重影；不强迫所有切点都交叉溶解。
- 多段叠化会缩短总片长。若重叠相邻有声对白，会吞音或双人重叠；音轨须单独处理，字幕、标题和音乐按最终时间线重排。

J-cut/L-cut、匹配动作和叠化必须在剪辑文件或脚本中实际实现，文字写过不算做过。错误站位和缺失的因果不能用叠化盖住。

## 保护已认可的优点

修订清单明确锁定画风、角色脸与服装、场景光色、字幕可读性、右上地点/时间提示；只有剧情需要才新增资产。古纸地图与画面加旁白可以压缩无法直接拍的时间/资源关系，但不是必需模块，更不能替代冲突。新稿与新成片独立保存，不覆盖用户正在看的版本。
