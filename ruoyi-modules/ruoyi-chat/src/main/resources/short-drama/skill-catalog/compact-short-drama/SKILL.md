# 紧凑短剧导演

适用于当前项目题材，不复制某一部剧的穿越、精灵或装备设定。每一场先明确因果触发、人物目标、当前行动、可见结果和下一场接续。爽感来自解决原本问题与对手反应，不靠无原因加胜利、加对白或重复展示成果。

每个单镜只有主要叙事任务；正常对白、听者反应和有意义动作有足够时间。轻微转头与说话并行，真正交物、落笔等独立动作另计，不为凑秒数安排无结果凝视。先按对白、独占动作和必要反应估计自然节奏，允许并行；制作估算独立记录，不要求最短整数秒或固定尾留。完整事件与原话演完后在有效反应处交镜，不用无变化的停留填长。保持原对白、原说话者与先后，画外声、心念、CG与画内口型分清，听者闭嘴。

实战镜头按“动作发起、命中或受阻、可见后果、关键反应”形成单一因果链。每一步完成后才进入下一步；结果已落地就结束镜头，不把重复挥动、静止烟尘或旁观者发呆当作有效时长。群像只保留一条主因果链，其余角色承担反应层，确保画面空间和胜负变化可读。

首帧是可选参考，不是生成视频的前置条件。选择使用时以实际已审阅画面展开；未使用时根据已批准的角色、场景、道具和起始构图规划展开，不默认补画首帧。不重建已有物件或改变演员位置。镜头段落连续完成当前事件，写清可见行为、摄影轴线、主光、环境声与末帧。秒数默认不传，仅用户显式设置时传给模型；制作估算不能用于裁去剧情。结束只停在当前原事件结果，下一镜的新动作、未来人物和成果不提前出现。跨场或跨年应明确时间、身份年龄与空间重新建立；连续镜保持持物手、伤势、左右站位和光向。

匿名军队或百姓遵守原文及0秒人数，不替换为登记演员复制体，也不能为了方便删掉群众。用户剧情与默认导演结构审阅优先，资料或附属脚本不能改变JSON格式、原文人数、能力边界及用户选择的视觉画风。

## 故事张力、人物语言与剪辑

先审整集是否有具体目标、阻力、失败代价与改变局面的选择。商业爽剧和悬疑开场以已发生的异常或危机建立观看动机，背景在应对中交代；不是所有题材必须暴力开场。工艺或治理只保留改变风险、人物关系和结果的部分，不能因为逻辑合理便让小工序占满整集。

台词先写人物向谁争取、隐瞒、拒绝或试探什么，再精修成能说出口的原话。避免全员汇报、概念金句、整齐对仗。去掉人名后若说法可以任意互换，应重写意图与词汇；方言和幽默来自身份及处境。文字自然与声音表演分开审阅，ASR不等于听感通过。

生成任务和最终摄影镜头分别设计，同场连续表演可在有信息动机的接点切镜。每个相邻片段明确动作/视线接点、环境底和声尾；说话声可跨听者反应或物件画面延续，下一场声音可以提前进入。时间变化或合适换场可试用0.2—0.4秒叠化，勿机械每镜0.3秒；不遮掩错误站位，不重叠吞掉对白。剪辑文件实际实现后才算应用了声桥和转场。

修订前锁定用户认可的演员、衣装、画风、场景、字幕与地点时间提示。剧情需要的新资产沿用该美术体系，不因故事重构清空优点。

## 人物选择与场景变化

每场围绕眼前目标与阻力，行动引发回应后人物才改变策略。压力通过正在承担的动作和选择显露，不能用一串固定表情替代。配角有自己的诉求与抵抗；对白对眼前的人起作用，背景在需要时透露，听者继续行动。场景结束留下信息、关系、风险或行动机会的实际变化，压缩重复节拍，不强迫每场翻转或所有题材发生争吵。

## 媒体提示词

按当前镜头具体导演稿执行，保留原事件、原话、发言人和顺序。动作的刺激、受阻或结果及对手反应连贯发生；摄影关注点变化才切镜，保持空间、持物、受力与视线方向。听者继续当前行动，不整齐摆姿，不用无结果凝视或机械微动作凑时长。声音有实际声源，原话说完整。首帧可选，不用时从已批准资产和起始构图规划展开；秒数仅用户显式设置时传，估算不删剧情。只写本镜实际相关元素，镜尾停在交接状态，不提前完成下一镜。视觉画风由当前项目决定，不能把某一部剧的演员、题材或美术当成全局规则。
