# Seedance · 一致性与续段提示词

## 参考职责

身份、地点、动作、摄影和声音分别说明参考来源。本镜实际出场和发言人以剧本为准；背景人物与画外声单独核对，参考画面中的无关内容不进入本剧。

## 连续动作

把本段主要变化拆成有先后和受力关系的行动，说明刺激如何引起人物回应。正文连续叙述，不沿用来源的逐秒清单。过程复杂时分配内部 timing 和并行关系，再让摄影跟随信息变化。
相邻段落交接具体姿态、位置、手物接触、物件状态和运动方向；已经完成的动作不重复，已发生的结果不撤销。延长和编辑需要所选接口真实支持，不能因为技能写到该能力就自动调用。
声音区分原对白、环境底声、动作拟音和音乐意图，对白保持角色归属。口型问题先查声源与画面注意重点，再调整机位或提示词，不能未经授权删改对白。

## 局部返修

记录失败的镜号与观察，将问题落到素材职责、动作、摄影或声音中的具体一项。仅调整失败单元，保留其他已批准结果。平台示例只能启发方法，不能被当成当前模型的参数或实测结果。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。

## 进出门与参考职责

场景母图约束建筑、陈设和材料，其摄影机所在一侧、门的开合和参考人物站位不自动成为本镜起点。生成前对照前段实际末态，说明参考负责什么；若母图视角与入场方向冲突，优先写清实际起始构图，按需关闭该图或改用已审阅画面，不默认新增付费图片。
跨门段交接人物在门内外的真实位置、门扇状态、锁钥匙去向与运动方向。开门和跨门分别核对；未入屋不提前出现在室内目标旁，已完成入场不重演，后续离场不提前。


## 进出动作审片

入场和离场对照前镜末态、开锁、门扇运动、跨门和抵达的完整运动及后镜起点。判断依据是人从哪一侧走到哪一侧，不能只凭门向内或向外开判断。抽一帧或结构检查只支持局部结论；重要跨门动作需连续播放或密集帧核查，记录未核查的运动与声音范围。返修保留其他通过素材，剪辑验证切口没有截断原对白或提前插入离场。
