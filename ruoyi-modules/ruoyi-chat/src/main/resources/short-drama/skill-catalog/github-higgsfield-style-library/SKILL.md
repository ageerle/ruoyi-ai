# 影视风格 · 题材与视觉方法库

## 风格路由

先区分电影写实、三维 CG、二维手绘、漫画运动、动漫动作以及产品广告。每类方法按当前故事和制作方向选用，不能把广告展示、两秒开场或技术术语当成短剧统一规范。

## 查阅与应用

从风格中提取可审阅的决定：人物比例、造型层次、材料反光、色板、空间深度、线条与光源。镜头方法说明如何让观众看清事件，声音说明如何支持变化；不靠精美、大片、8K 等词替代这些决定。
电影、CG、手绘、漫画运动和动漫的项目适配条目分别保存在审美分类，可按实际方向选择。其他电商、品牌、时装、食物和建筑条目只作相关场景参考，不进入默认短剧生成。
上游对输出分辨率、帧率、同步准确性和渲染引擎的描述不代表本项目供应商能力。没有完整影片或同配置实验时，保持方法参考的证据级别。

## 接入范围

本条归视觉风格，在资产配置中选中后，根据当前题材提炼统一的造型、材质、色彩与光影方向，不混用资料库内的全部画风。公开仓库未核到明确再分发许可，正文为本项目自主编写的方法，来源只登记链接、提交和阅读范围，不打包上游全文或媒体。

## 项目接入边界

本技能提供当前阶段的制作方法，沿用项目现有数据、输出结构、模型目录与内容审阅。用户原文、已批准资产和当前项目决定优先；来源示例不是本剧事实。模型参数与参考语法交给本项目实际供应商适配，不从旧手册推定平台能力。
首帧按需使用，不是生成前置条件；不默认补图。视频正文采用连续导演描述，时长预算独立保存为 timing。写作、修订和技能安装不会提交付费图片、视频、配音或音乐任务。附属脚本仅作文本资料。
修订已有分镜保留已批准图片、连续性、素材任务编号和制作版本；当前只处理有问题的阶段。结构检查、任务完成与成片画面、运动和声音验收分别记录。
