本项目采用的核心方法：先决定观众获得的新信息；每镜明确单一视觉重点；景别和运镜服务信息变化；先确定动作切点再设计首帧；相邻镜保持轴线、方向、身份和物理状态。将其落实为 `shot_design`，由规划输出、细化保留、入库检查和前端卡片共同使用。

未照搬平台模型、固定镜数、阶段审批口令或第三方程序。声音术语按实际剪辑定义：J-cut 是下一镜声音提前进入，L-cut 是上一镜声音延续。规则和结构检查不能证明生成图、视频已经符合镜头设计，仍须查看实际画面和声音。
