# 二维手绘 · 线条与色板

## 视觉决定

按本剧批准方向选择稳定线条、造型比例和主辅色，人物轮廓、发束、服饰边缘与道具形态在不同景别保持。手绘、平涂、水彩和水墨是不同材料方向，不能把无渐变规则套到水彩或墨色过渡。
场景空间可简化但位置、尺度与接触关系清楚，人物动作保留重心和轮廓可读性。纹理和边缘变化体现选择的画材，避免三维塑料高光混入二维平涂。阴影和光源属于同一场景规则，沿已批准画面逐张核对。

## 资产审阅
