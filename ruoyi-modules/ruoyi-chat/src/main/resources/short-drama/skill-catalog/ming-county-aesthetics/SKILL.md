# 明代县域资产审美

范围：明代县域题材。跨时代故事的现代序幕仍按当前时点制作，不能套官袍。无法核实的袖型、帽翅角度与配色标记为原创动画设计约定，不用生成图证明史实。

官员先区分朝服、公服、常服及当前穿着场合，不能把公服品色和常服补子混成同一制度。圆领要有闭合领口和贴合颈根的领缘，宽袖有重量，革带与袍下摆受力自然；乌纱帽贴合头围、前低后高、两侧帽翅清楚。补子按具体官阶核实，不能把县令随意配帝王龙、麒麟、仙鹤或狮纹；未核实鸟纹先做待审简化方补，不能缩成现代胸牌或清代开襟两半。

差役和工匠按本剧已确定衣物：厚布收袖与普通腰束，劳动者棉麻交领、既有完整皮围裙。普通乡民可用米白、靛蓝、赭褐的棉麻分组，局部修补服从磨损位置，不统一灰黑泥脸或相同五官。脸形、年龄、劳动体态和原有左右记号比堆饰品更能区别身份。

县衙以木案、纸卷砚、桌椅通行区、土灰墙木柱格窗形成三层。普通木材保留榫接和支撑，朴素修补，不复制宫廷名贵木料与满墙花雕。工坊以土石炉座、木台、夹钳、炭筐和当前半成品按功能摆放，金属木布材质分别控制高光。县城规模、墙体、道路和运河岸线来自项目明确阶段与地域，早期低旧土墙不能悄悄升级成成熟巨城，鲁西南县域不能套江南水乡统一模板。
