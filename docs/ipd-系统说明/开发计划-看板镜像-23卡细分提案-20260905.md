## 通用口径

- **错峰单模块命令**：`mvn -o -pl ruoyi-modules/ruoyi-ipd -Dtest=Xxx test`（不带 `-am` / `clean`，符合 OPS-09）
- **真库 HTTP 验收**：`start_new_session` 起 jar + curl HTTP + DB 校验（不依赖 mock）
- **commit 前必跑**：`manage.py check` 漂移复核
- **单写入者纪律**：同一文件多个会话不重叠；新会话认领须先在镜像写"责任人"
