## A. 真实冲突（必须解决）

### A.1 硬约束数量表述差异

| 文档 | 表述 | 数量 |
|---|---|---|
| v3 Prompt §0 | 「**七大**强制顶层硬规则」 | **7 条** |
| 开发说明书 §3 | G-01 ~ G-11 | **11 条** |

| 验收清单 | 引用 G-01~G-11 | **11 条** |

**实际差异**（不冲突，但表述不一致）：

v3 Prompt 列的 7 条是「最高优先级核心硬规则」（G-01~G-07），但**完整**硬约束还包括：
- **G-08**：涉钱参数必须可切换（奖金池基数等 6 项）
- **G-09**：角色体系不扩展（不新增「评审上级」「代理组长」）
- **G-10**：市场 PM 视角优先（研发 PM 阶段默认轻管，**禁附件按钮**）
- **G-11**：数据库双账号分离（`ipd_app` 运行时 + `postgres` 迁移）

**v3 Prompt 的 7 条 → 完整 11 条的扩展关系**：

| v3 Prompt | 对应硬约束 |
|---|---|
| ① 业务闭环 | = G-01 |
| ② 分层组织权限体系 | = G-02 |
| ③ 差异化删除审核机制 | = G-03（含子规则）|
| ④ 严格落地双PM制度V3.1 | = G-04（制度优先）|
| ⑤ 超管人事移交闭环 | = G-04 子项（无独立编号）|
| ⑥ 全生命周期管控 | = G-01 子项 |
| ⑦ AI内容管控规则 | = G-04 子项（无独立编号）|
| **未列** | **G-05 参数可配置** |
| **未列** | **G-06 无绝对化承诺** |
| **未列** | **G-07 中文界面** |
| **未列** | **G-08 涉钱参数** |
| **未列** | **G-09 角色体系** |
| **未列** | **G-10 市场PM视角优先** |
| **未列** | **G-11 数据库双账号分离** |

**问题**：v3 Prompt 的「7 条」容易让人误以为只有 7 条硬约束。但开发说明书 / AI 必读 / 验收清单是完整 11 条。

**修复（仅 ipd-系统说明/ 内部，**不动 v3 Prompt 也不动开发说明书**）**：

- 在 `docs/ipd-系统说明/README.md` 加「硬约束映射」段，说明 v3 Prompt 7 条 vs 完整 11 条
