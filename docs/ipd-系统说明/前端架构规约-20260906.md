## §5 强制执行机制（机器层）

### 5.1 PreToolUse hook（写入即阻断）

- 文件：`.claude/helpers/ipd-frontend-drift-guard.cjs`
- 注册：`.claude/settings.json` 的 `Write|Edit|MultiEdit` matcher
- 触发时机：任何 Write/Edit/MultiEdit 命中 `apps/web-antd/src/api/ipd/*.ts` 或 `views/ipd/<domain>/<domain>-error.ts`
- 阻断规则：
  1. 写 `views/ipd/<domain>/<domain>-error.ts` → exit 2（强制走 `_shared`）
  2. 写 `api/ipd/product-group.ts`（Write 模式）→ exit 2（用 Edit 走兼容层）
  3. 在 `api/ipd/*.ts` 新增 export 与其他 `api/ipd/*.ts` 冲突 → exit 2

### 5.2 自检脚本（CI / 治理轮 / 手动）

- 文件：`scripts/check-ipd-frontend-drift.sh`
- 4 项检查：
  1. api/ipd/*.ts 同名导出冲突
  2. views/ipd/<domain>/<domain>-error.ts 中是否仍含实函数（应只剩 re-export）
  3. api/ipd/product-group.ts 是否带 @deprecated 标注
  4. views/ipd/**/*.vue 中手写"待后端"占位但未引用共享组件
- 退出码：0 干净 / 1 有漂移 / 2 脚本错误
- 推荐接入位置：`.github/workflows/ipd-frontend-drift.yml`（CI）；治理轮（Vibe Kanban AUD-GOV 卡）

### 5.3 agent 认领前守则（在 `.claude/agents/*.md` 中强化）

新增卡面（fe-* 智能体）认领前：
1. **必跑**：`bash scripts/check-ipd-frontend-drift.sh` —— 看基线
2. **必 grep**：`grep -rln '<新加函数名>' apps/web-antd/src/api/ipd/` —— 确认无冲突
3. **必查**：`docs/ipd-系统说明/前端架构规约-20260906.md` 本文档 §3 共享层表
