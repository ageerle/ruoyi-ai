## 关键内容（推断）

按 Element Plus 默认 + RuoYi-AI 定制推断：

### 1. 按钮

| 尺寸 | 高度 | 圆角 | 字号 |
|---|---|---|---|
| large | 40px | 4px | 14px |
| default | 32px | 4px | 14px |
| small | 24px | 4px | 12px |

### 2. 表格

| 维度 | 值 |
|---|---|
| 行高 | 44px |
| 表头背景 | #F5F7FA |
| 边框 | 1px solid #EBEEF5 |
| 分页位置 | 右下角 |
| 多选列宽 | 50px |

### 3. 表单

| 维度 | 值 |
|---|---|
| 标签对齐 | 右对齐 |
| 必填星号 | 红色 * |
| 校验失败 | 红色边框 + 错误文案 |
| 提交按钮 | 右对齐 |

### 4. 弹窗（Dialog）

| 尺寸 | 宽度 |
|---|---|
| 小 | 500px |
| 中 | 800px |
| 大 | 1100px |

### 5. 输入框

| 高度 | 圆角 |
|---|---|
| 32px | 4px |

### 6. 业务组件（项目定制）

| 组件 | 规格 |
|---|---|
| 六阶段流程条 | 横向 6 段，已完成主色实心 / 当前描边 / 未开始灰色；阻断未过时下一阶段置灰 |
| 深管动作卡片 | 白卡片 + 主色左边框 4px |
| 轻管动作行 | 灰色紧凑行，**无附件按钮** |
| D11 特例行 | 额外显示 FAR / FRR |
| Gate 要素判定表 | 三态单选（✅/⚠️/❌） |
| 双签状态条 | 两列并排，互不可见 |
| 禁用态 | 权限不足不隐藏入口 |
