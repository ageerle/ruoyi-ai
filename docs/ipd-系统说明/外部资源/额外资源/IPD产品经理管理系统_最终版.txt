# IPD产品经理管理系统・最终完整版 AI 开发 Prompt（全部规则闭环，无遗留疑问）
## 【全局系统定义 & 最高优先级强制顶层规则】
请你作为资深全栈产品开发工程师，完整落地一套企业级、100%全业务闭环、差异化删除审核、分层权限管控、可审计、带AI赋能的IPD产品经理数字化管理系统。
> 业务依据：《双产品经理绩效考核制度 V3.1》，完整落地双PM RACI决策矩阵、五大联合Gate节点、双签否决机制、L1‑L5月度津贴、项目分级差异化奖金池系数、在研项目适配规则。

系统核心定位：标准化IPD研发流程落地 + 双PM组队考核激励 + 新旧双模式项目管理 + 免登录需求收集 + 一键项目人事移交 + IPD全流程AI资料辅助生成 + 全业务流程闭环 + 产品组层级权限体系 + 差异化删除审核闭环 + 超级管理员人事移交机制。
系统核心使用角色：外部游客、普通产品经理、产品组长、市场PM、研发PM、超级管理员。

**七大强制顶层硬规则（最高优先级，必须严格落地）**
1. **全业务100%闭环**：系统所有流程、动作、提交、审核、变更、移交、奖惩、需求、任务必须形成完整闭环，有发起、有处理、有审核、有结果、有记录、有归档、可追溯，无烂尾流程、无数据断层、无权限漏洞。
2. **严格分层组织权限体系**：严格区分超级管理员、产品组长、普通产品经理三层权限视图与操作边界；一个产品经理仅归属一个产品组。**市场PM、研发PM人员禁止在系统内手动新增，全部通过第三方API接口同步获取；执行每月定时check任务，自动从第三方系统拉取新增人员更新至本系统；保留本地文件批量导入仅用于存量初始化，日常人员维护完全依赖第三方API**；人员数据变更操作全部写入审计日志。
3. **差异化删除审核机制**：项目重大Gate节点、立项关键信息、核心交付物、需求池需求记录执行双层审核（组长初审+超管终审）；普通归属PM独立业务信息执行组长一级审核；任何人无直接删除权限。
4. **严格执行双PM制度V3.1规则**：落地五大联合Gate，立项Go/No‑Go、需求变更、上市复盘三项双签否决；否决后需重新发起评审；Gate评审附件为强制交付物；冲突升级双方组长仲裁，仲裁结果写入审计日志；完整实现L1‑L5月度津贴、项目S/A/B分级差异化奖金池系数、贡献度浮动分配；PM项目数量≥3个弹窗校验备案；连续两月无产出自动提醒管理员复核津贴。
5. **超级管理员人事异动完整移交闭环**：支持超级管理员账号、系统最高权限、后台配置完整安全交接，移交后原超管账号禁止登录，保障系统永续运维。
6. **项目生命周期规则**：IPD生命周期运维阶段持续至产品停产，停产归档后仅可查看导出，不可编辑修改。
7. **AI模块约束**：AI输出内容系统不做敏感过滤，直接透传大模型返回结果，必须由产品经理人工审核后方可归档，保留完整版本链。

## 【新增：人员对接与登录认证能力】
1. **人员信息对接导入规则**
- 市场PM、研发PM**不允许在系统页面手动新增人员**，人员数据源完全依赖第三方系统API接口；系统配置每月定时check同步任务，自动从第三方系统拉取新增人员、人员属性变更、离职状态变更同步至本系统。
- 保留本地文件批量导入仅用于系统初始化存量数据导入，日常人员维护全部走第三方API。
- API同步的人员信息包含姓名、所属产品组、PM类型（市场PM/研发PM）、L1‑L5等级、人员在职/离职状态等核心字段；人员新增、变更、离职状态变更全部写入审计日志。

2. **系统两套登录方式（市场PM/研发PM/产品组长适用，游客无需登录）**
    - 方式一：账号密码登录
      - 用户名：使用导入后的PM人员姓名作为用户名；
      - 系统初始化可为新导入人员分配**系统默认密码**；**无密码过期时间，仅强制首次登录必须修改默认密码；未执行首次登录修改前，默认密码持续有效**；密码修改行为记入审计日志。
    - 方式二：企业微信扫码登录
      - 市场PM、研发PM、产品组长支持企业微信扫码授权登录；企业微信账号需要与系统内已导入的PM人员信息做账号绑定校验，绑定后方可扫码登录。
      - 当第三方API同步识别该人员为离职状态，**系统自动解除该账号的企业微信绑定关系，同时账号禁止登录**。
> 超级管理员账号独立管理，不受上述用户名规则约束，可独立配置账号密码登录。

## 【核心功能1：全量IPD六阶段固化+标准化SOP流程体系 + 双PM联合Gate决策（全闭环）】
1. 系统底层预置完整标准IPD六大研发阶段（概念阶段、计划阶段、开发阶段、验证阶段、发布阶段、生命周期运维阶段），阶段固定不可删除，后台支持管理员自定义修改各阶段细则。
2. 每个IPD大阶段下，内置该阶段所有标准执行动作、工作节点，形成标准化流程清单。
3. 每一个执行动作强制绑定专属SOP标准作业程序（富文本说明+附件上传入口），供产品经理随时查看、对标执行。
4. 所有项目（新项目+导入在研项目）自动挂载统一IPD流程体系，支持可视化流程视图展示。
5. 设置**阶段门禁闭环机制**：当前阶段核心动作未完成、无交付产出、未归档资料，禁止跳转至下一研发阶段，强制流程闭环。
6. 每个动作支持状态管理：未开始、进行中、已完成、延期；支持填写执行记录、上传阶段交付物、留存过程资料、完结归档，全程闭环可追溯。
7. **五大联合Gate重大决策节点**：Go/No‑Go立项、差异化确认、开发双周评审、GTM就绪、上市后90天复盘。
8. Gate节点约束：**Gate评审附件（会议纪要、评审材料）为强制交付物，不完成上传则Gate节点无法闭环**。
9. **双签否决规则**：立项Go/No‑Go、需求变更审批、上市后复盘三项执行双签否决，任一方否决则事项直接驳回；如需再次评审，需要手动重新发起评审流程；其余决策按照RACI矩阵分工，一方主导，另一方参与咨询或仅知会备案。
10. 双PM重大节点意见冲突无法达成一致时，升级至双方各自产品组长进行仲裁；**仲裁决策结果写入项目审计日志永久归档**。
11. 在研导入项目执行：**已过节点不追溯，未过节点由双PM接管；需求变更双签、上市节奏决策、上市复盘机制立即生效**。
12. IPD生命周期运维阶段：产品上市后持续维护，直到标记产品停产，项目正式归档关闭；归档后仅允许查看、导出全部资料，禁止编辑、新增、修改、删除。

## 【核心功能2：双PM（市场PM+研发PM）绩效考核与双轨激励体系（对齐制度V3.1，全闭环）】
系统搭建双角色、双模式独立激励机制，区分**L1‑L5月度等级津贴、产品成功奖金池**两套体系，从立项‑约定目标‑上市‑统计‑核算‑台账记录全程闭环。
> 系统仅做台账记录统计，**不对接财务薪资系统**。
1. 角色配置：所有项目固定采用「市场PM+研发PM」双人负责制，绑定项目全生命周期。
2. **月度等级津贴（L1‑L5评级）**
    - 后台PM人员档案数据来源于第三方API同步；初始化支持文件批量导入，配置L1~L5能力等级，对应固定月度津贴标准：L1=1000、L2=1500、L3=2000、L4=2500、L5=3000。
    - 津贴额度**按项目启动/PM补入项目时的评级锁定**；新项目使用最新评级；多项目津贴叠加，个人月津贴总额封顶为本人当前评级额度2倍。
    - 业务校验：同一个PM绑定项目数量≥3，弹出弹窗校验，要求录入评级委员会审批备案记录，否则禁止绑定第3个及以上项目。
    - 自动提醒机制：附加项目连续2个月无实质产出，系统自动提醒管理员复核津贴发放资格，仅提醒，不自动停发津贴。
    - 当月综合考核分数＜60分，当月停发津贴；触发负反馈按制度执行扣减。
    - 项目发生PM移交，月度津贴跟随新接手PM，按接手时该PM自身等级核算；已过去阶段津贴不追溯重算。
    - 系统生成月度津贴台账报表，仅用于内部对账留痕。
3. **产品成功奖金池（项目后置考核全闭环）**
    - 项目立项阶段录入：上市后6个月目标回款金额、项目等级S/A/B；项目等级创建时选定，**项目中期允许修改，修改操作写入审计日志**。S/A/B对应差异化系数。
    - 统计口径：以**回款金额**作为奖金池计算基数；奖金池 = 上市后连续6个月实际回款金额 ×5% ×项目差异化系数。
    - 上市6个月结束之后发生退款，不做奖金回溯扣减，该场景不处理。
    - 奖金发放二次修正因子：销售达成率阶梯系数、个人绩效系数；市场PM、研发PM贡献度占比浮动区间：市场40%‑65%，研发35%‑60%，上市90天复盘由双PM+上级三方评定。
    - 项目中途PM发生人员变动移交（包含市场PM、研发PM同时移交场景）：**完整保留全部Gate评审历史、奖金池台账、全流程数据；月度津贴按新PM等级执行；奖金池沿用项目立项既定规则，系统支持人工补充登记特殊分配备注，留痕归档**。
    - 存量导入在研项目完整启用整套奖金池规则，无特例关闭。
    - 系统只输出奖金台账记录，不生成财务正式结算单据，支持报表导出归档。

## 【核心功能3：双项目入驻模式——新项目招标组队 + 存量在研项目一键导入（全闭环）】
> 系统初始化阶段，支持批量文件导入全部市场PM、研发PM人员名单；日常人员维护全部依赖第三方API每月定时check同步。
1. 全新项目（招标组队模式）
    - 市场PM发起新项目，发起研发PM招标，支持两种招标模式：
      ①一对一邀标：定向邀标指定研发PM；**一对一邀标仅限被邀研发PM本人应标，不可转发给其他研发PM**；
      ②公开招标：面向全部研发PM公开投标。
    - 每个项目独立设置招投标有效期。
    - 市场PM可在招标有效期内**中途修改招标条件、手动关闭招标单，操作写入审计日志**。
    - 研发PM可以选择拒绝应标，拒绝行为不留系统痕迹。
    - 招标到期，无研发PM应标，系统提醒市场PM重新发起招标。
    - 研发PM应标后，由发起项目的市场PM做最终遴选，确定研发PM人选。
    - 组队完成生成项目，自动挂载完整IPD流程与Gate决策机制，流程闭环。
2. 存量在研项目（免招标导入模式）
    - 有权限人员导入项目→补录当前IPD阶段、历史资料、指定市场PM&研发PM信息→接入系统完整流程、双PM权责、奖金池规则，接续推进；新旧项目纳入统一管控闭环。

## 【核心功能4：免登录游客需求管理系统（需求全生命周期闭环）】
搭建公开无登录需求反馈门户，实现**需求提交‑收录‑分派‑处理‑跟进‑关闭‑归档**完整闭环：
1. 外部/内部人员无需登录，即可提交产品需求。
2. 固定提交字段：选择产品、提交人、负责人、需求描述、附件上传。
3. 游客提交需求后，游客无系统账号，**无法修改、撤回提交的需求**。
4. 需求自动汇入需求池，自动通知对应PM。
5. 内部PM可做评估、排期、处理、更新状态、关联项目IPD节点、完结归档，需求生命周期100%闭环。
6. 需求池内的需求记录删除，属于重大数据，强制双层审核：产品组长初审 + 超级管理员终审。

## 【核心功能5：产品经理人事变动·一键全量项目移交体系（人事交接闭环）】
专为人员异动设计项目权责交接闭环，无数据丢失、无权责断层：
1. 支持单项目 / 批量项目一键移交，支持市场PM、研发PM角色独立移交，支持同时移交两个角色。
2. 移交后，**项目全部历史审批记录、Gate评审记录、决策日志、文档资料、奖金池台账完整跟随项目移交至新PM**；新PM继承全部权限，接续推进未完成流程。
3. 全程生成审计日志永久留存，交接流程闭环可审计。

## 【核心功能6：IPD全流程AI大模型智能辅助资料生成能力（资料产出闭环）】
1. 后台支持配置AI大模型参数、开关。
2. 覆盖IPD全阶段文档产出：PM录入原始资料 → AI智能润色、补齐、标准化生成 → **产品经理人工审核确认之后，才允许保存归档**。
3. AI生成内容保存**完整全版本链，包含AI原始输出、后续全部人工修改版本，支持版本回溯查看**。
4. AI输出内容系统**不做敏感内容过滤，直接透传大模型返回结果，由PM人工把控内容风险**。
5. AI调用权限：普通产品经理、产品组长权限对等，均可调用已配置大模型做资料生成与AI分析。

# 【新增核心规则1：产品组层级权限体系 + 差异化删除审核闭环】
系统组织架构层级：**超级管理员 → 产品组长 → 普通产品经理（市场PM/研发PM）**
> 约束：一个产品经理仅归属一个产品组。

## 1、普通产品经理权限
- 查看权限：仅可查看本人负责的项目，无法查看本组其他PM项目。
- 编辑权限：可自主编辑、新增、补充自己负责项目的信息、流程、文档、记录。
- 删除权限：无直接删除权限，仅可发起删除申请。

## 2、产品组长权限
- 查看权限：可查看本组所有产品经理全部项目、进度、资料、台账，实现全组监管。
- 编辑权限：可自主编辑新增自己名下项目资料；可以查看监管组员项目，但不可随意修改组员项目数据。
- 审核权限：处理本组删除申请的初审。

## 3、差异化删除审核铁律
1）**重大节点Gate记录、立项关键信息、核心交付物、需求池需求记录**：删除申请 → 产品组长初审 → 超级管理员终审，两级全部通过方可删除。
2）归属市场PM独立负责普通业务信息：删除申请 → 对应产品组长初审。
3）归属研发PM独立负责普通业务信息：删除申请 → 对应产品组长初审。
4）驳回处理：删除申请被组长/超管驳回，系统通知申请人，完整保存驳回记录。
5）所有删除申请、审核、驳回、执行全部写入审计日志；任何人不允许直接删除数据。

# 【新增核心规则2：超级管理员角色 + 超级管理员人事异动移交闭环机制】
1. 超级管理员为系统最高权限：全权负责系统参数配置、AI模型配置、组织架构管理、账号权限开通、PM L1‑L5等级津贴配置、重大删除单据终审、全局数据管理；超级管理员账号独立，不使用PM姓名作为用户名，独立管理登录凭证。
2. 超级管理员人员变动专属移交功能（完整闭环）
   - 系统内置【超级管理员权限一键移交】功能模块。
   - 旧超级管理员将全部系统最高权限、后台配置、AI模型配置、审核权限、数据管理权限、系统参数完整迁移至新超级管理员账号。
   - 移交需要二次确认，全程日志留痕；移交完成后，旧超级管理员账号**禁止登录系统，账号作废不可使用**；系统保留完整移交记录，新超级管理员可查看历史移交信息以及原超级管理员身份。

# 【审计日志通用规则】
1. 招标修改/关闭、仲裁决议、项目S/A/B等级修改、删除申请审核、项目移交、超级管理员移交、第三方API人员同步变更记录、密码修改记录、企业微信账号绑定/解绑记录等全部关键操作写入审计日志。
2. **系统所有角色均支持导出审计日志**。

# 【最终全局强制闭环要求】
1. 业务闭环：项目、IPD Gate评审、需求、绩效、移交、审核、文档全部有始有终、可追溯、可归档。
2. 审核闭环：区分重大数据与普通业务数据使用不同审核链路；驳回通知申请人，完整留存驳回记录。
3. 权限闭环：三层角色权限严格隔离；编辑自主，删除必须走申请审核流程；组长监管，超管终审重大删除项。
4. 数据闭环：所有新增、编辑、审核、申请、驳回、删除、移交、参数修改、第三方人员同步全程留痕，不可篡改，支持导出审计。
5. 流程闭环：全系统无断点、无空节点、无游离数据，所有业务走完标准闭环链路。

# 【系统最终角色权限总结】
1. 游客：仅可免登录提交产品需求，无任何其他操作权限。
2. 普通PM：自有项目可新增/编辑，仅可发起删除申请，无权直接删除，仅查看自有项目；拥有AI调用权限；支持账号密码（姓名为用户名）、企业微信扫码两种登录方式。
3. 产品组长：全组项目可视、自有项目可编辑、负责本组删除申请初审、无直接删除权限；拥有AI调用权限；支持账号密码（姓名为用户名）、企业微信扫码两种登录方式。
4. 超级管理员：系统最高配置权限、重大删除单据最终终审权、超管权限移交管理权、全局数据管理权；独立账号密码登录，不适用PM登录规则。
