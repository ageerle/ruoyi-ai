# IPD 六阶段标准动作清单（v2 · 按管理深度分级）

> **v2 变更**：按 Gavin 要求，系统工作重心偏向市场PM。全清单按「管理深度」分为两级：
> 
> - **深管**（市场PM 主导）：完整动作管理 —— 状态流转、执行记录、强制交付物上传、SOP 关联、参与阶段门禁阻断
> - **轻管**（研发PM 主导）：**仅登记完成状态 + 实际完成日期 + 备注（选填）**，不强制上传任何文件，不阻断阶段流转
> 
> 深管 35 个 / 轻管 25 个，合计 60 个动作。

---

## 管理深度定义（开发必须实现）

### 深管动作 — 完整管理

| 能力   | 说明                             |
| ---- | ------------------------------ |
| 状态流转 | 未开始 → 进行中 → 已完成 / 延期，每次变更写操作记录 |
| 执行记录 | 富文本，支持多次追加                     |
| 交付物  | **强制上传**，至少 1 个附件方可标记"已完成"     |
| SOP  | 强制展示该动作绑定的 SOP 富文本说明           |
| 门禁   | 阻断性动作未完成时，禁止跳转到下一阶段            |
| 提醒   | 到期前 3 天 / 逾期每天提醒主责人            |

### 轻管动作 — 三要素登记

**界面只需三个字段，不要做过载设计：**

| 字段     | 类型                       | 必填          |
| ------ | ------------------------ | ----------- |
| 完成状态   | 枚举：未开始 / 进行中 / 已完成 / 不适用 | 是           |
| 实际完成日期 | 日期                       | 状态为"已完成"时必填 |
| 备注     | 文本，≤200 字                | 否           |

**轻管动作明确不做的事：**

- ❌ 不强制上传交付物（可选上传，但不校验）
- ❌ 不强制展示 SOP
- ❌ 不阻断阶段流转（法规认证类除外，见下）
- ❌ 不做执行记录富文本

**例外**：涉及**法规认证**的轻管动作（P10 认证规划、V02 认证送检）保留阻断性，因为认证缺失会导致产品无法上市销售——但同样不强制上传证书扫描件，只需登记"已通过 + 通过日期 + 证书编号（文本）"。

## 与 V3.1 五阶段映射关系

| V3.1 五阶段 | 周期       | 本系统 IPD 六阶段     | 主责        |
| -------- | -------- | --------------- | --------- |
| 立项决策     | 2–4 周    | 阶段一 概念          | 市场PM      |
| 方案设计     | 2–3 周    | 阶段二 计划          | 市场PM（需求侧） |
| 开发推进     | 按排期      | 阶段三 开发 + 阶段四 验证 | 研发PM      |
| 上市 GTM   | 1–2 周    | 阶段五 发布          | 市场PM      |
| 复盘迭代     | 上市后 90 天 | 阶段六 生命周期        | 市场PM      |

**保留 IPD 六阶段而非改用 V3.1 五阶段**的原因：开发+验证是两个性质完全不同的阶段（一个产出、一个验证），合并后阶段门禁与交付物管理会失真。系统内部用六阶段，对外汇报视图可切换为 V3.1 五阶段。
