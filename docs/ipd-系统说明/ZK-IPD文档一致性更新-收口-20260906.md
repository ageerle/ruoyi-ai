### 章节定位体系（权威）

ZK-IPD Prompt 章节结构：

- **§一**：全局系统定义 + 7 条强制顶层硬规则
- **§二**：核心功能 1 — IPD 六阶段 + 双 PM Gate 决策体系（编号 1-10）
  - §二.7 = 三项双签否决
  - §二.10 = 项目生命周期（归档后只读）
- **§三**：核心功能 2 — 双 PM 绩效考核与双轨激励体系
  - §三.1 = 月度等级津贴规则（编号 1-5：L1-L5 / 2 倍封顶 / PM≥3 弹窗 / 长期无产出 / 60 分停发）
  - §三.2 = 项目奖金池规则（编号 1-6：公式 / 退款 / 等级 / 分配比例 / **修正因子（含达成率阶梯系数）** / 项目移交适配）
- **§四**：核心功能 3 — 招投标组队
  - §四.1 = 招标模式规则（编号 1-6：两种模式 / 一对一仅指定 / **到期无人应标提醒** / **拒绝不留痕** / **修改条件通知 PENDING** / **应标完成后市场 PM 遴选**）
  - §四.2 = 双建项模式
- **§五**：核心功能 4 — 免登录游客需求（编号 1-5，§五.5 = 需求池删除双审）
- **§六**：核心功能 5 — 项目一键移交（§六.2 = 历史保留跟随项目迁移）
- **§七**：核心功能 6 — AI 辅助（§七.3 = 完整全版本链路 / §七.5 = 权限平等）
- **§八**：角色权限 + 差异化删除铁律（§八.2.1 = 双审 / §八.2.2 = 单审）
- **§九**：超管权限移交规则（编号 1-3：迁移全部权限 / **二次确认 + 原超管作废** / 永久留存移交记录）
- **§十**：审计日志通用规则（§十.2 = 所有角色可导出）
- **§十一**：全局闭环强制要求（编号 1-5）

**关键事实**：

1. ZK-IPD **没有 §X.Y.Z 三级章节定位**——只有 §一~§十一 一级 + 核心功能 N 二级 + 编号 1-6 三级
2. ZK-IPD Prompt 是 **中文 Markdown 描述文档**，**没有 JS 字段名**（如 `actualReceipts` / `targetSales`）
3. ZK-IPD §三.2.5 原文："**奖金可叠加销售达成率阶梯系数、个人绩效系数**" → tierCoefficient 是 **ZK-IPD §三.2.5 修正因子** 概念，**不是自创**
4. ZK-IPD §四.1.6 原文："**应标完成后，由发起项目的市场PM独立遴选、确定最终研发PM人选**" → "30 日挂起超管指派" **不是 §四.1.6 概念**，是 ZK-IPD 未明示的自创工程优化

### 字段术语标准命名（ZK-IPD Prompt 原文）
- **奖金池**：上市后连续 6 个月**实际回款**金额 × 5% × 项目 **S/A/B 差异化系数**
