### 2.3 5 步产物

#### Step A：AC → Given/When/Then

- **AC-INC-34 正例**：导出津贴/奖金 Excel → headers 中文 + 金额 (元) 保留 2 位 + 行含中文 key
- **AC-INC-34 反例**：month 格式非法 → 400 PARAM_INVALID（service 层拦截）
- **BR-INC-15 不重复计数**：allowance SUM(finalAmount) GROUP BY projectId WHERE month=?；bonus SUM(finalPool) GROUP BY projectId；score AVG(weightedScore) GROUP BY projectId WHERE status='CONFIRMED'
- **BR-INC-15 同范围同筛选**：{@link IpdReportService#listProjectSummaries} 与 {@link IpdReportService#exportProjectSummary} 共用 {@link IpdReportService#resolveProjectFilter} 解析 month+productId+keyword
- **BR-INC-15 金额单位**：{@code finalPool.setScale(2, RoundingMode.HALF_UP)} 统一
- **BR-INC-15 大数据分页**：{@code MAX_PAGE_SIZE=500} 列表 / {@code MAX_EXPORT_SIZE=5000} 导出
- **BR-INC-15 脱敏**：导出仅含业务字段，headers 固定 15/14/10 列中文
- **BR-INC-15 导出审计**：{@link IpdReportService#appendExportAudit} 写一条 EXPORT_REPORT 审计，独立事务落名（operatorId/Name/Role + action + entityType + reason count=N month=...）
