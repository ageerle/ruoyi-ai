## 1. 业务规则映射（ZK-IPD §X）

### 1.1 来源（ZK-IPD Prompt §三.2.5 / BR-INC-09）

- 五维度权重（**权重和 = 100%**）：
  - 立项主导贡献 25%
  - 差异化创新贡献 25%
  - 上市节奏把控 20%
  - 市场结果贡献 20%
  - 协同领导力 10%
- 市场 PM 浮动区间 **40% – 65%**，研发 PM 浮动区间 **35% – 60%**
- 两者之和恒为 **100%**（AC-INC-25，前端联动校验；后端为权威）
- 评定入口**仅在 G5 上市后 90 天复盘阶段开放**（AC-INC-28）
- 评定人 = **双 PM 自评 + 各自产品组长**（A5 决策：直接上级 = 产品组长，系统内无「评审上级」角色）

### 1.2 引用 AC（ZK-IPD 验收清单）

| AC | 预期 | 落点 |
|---|---|---|
| AC-INC-25 ⚠️ | 贡献度：市场 65% → 研发自动联动为 35% | `ContributionService.linkRdShare()` |
| AC-INC-26 | 贡献度：市场 70% → 拒绝保存（区间 40%-65%） | `ContributionService.validateMarketShare()` |
| AC-INC-27 | 五维度权重和 = 100% | `ContributionService.validateDimensionWeights()` |
| AC-INC-28 🆕 | 入口仅 G5 开放；需双 PM 自评 + 各自产品组长评定 | `ContributionService.requireG5Stage()` |
| AC-INC-29/29b/29c/29d | 完整公式验证（含 tierCoefficient 修正因子） | 已被 `BonusPoolService` 覆盖，本卡专注贡献度字段 |

### 1.3 引用 BR

- **BR-INC-09**：贡献度评定五维度（市场40%-65% / 研发35%-60%，五维度权重和 = 100%）
- **BR-INC-10**：负反馈机制（与 P3-8.2 负反馈执行联动；本卡不实现负反馈逻辑）

## 2. API 契约

### 2.1 路径

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/contributions/{projectId}` | 查询项目最新贡献度评定（返回双 PM 五维度 + 市场比例） |
| POST | `/api/v1/contributions/{projectId}/save` | 保存/更新双 PM 自评（五维度原始分数） |
| POST | `/api/v1/contributions/{projectId}/confirm` | 产品组长确认贡献度比例（同时落市场PM权重） |
| POST | `/api/v1/contributions/{projectId}/market-share` | 调整市场 PM 比例（40-65% 区间校验，研发联动） |
| GET | `/api/v1/contributions/{projectId}/preview` | 公式预览（不改库；返回 tierCoefficient 修正因子） |

### 2.3 错误码

| 错误码 | HTTP | 场景 |
|---|---|---|
| `CONTRIB_TIER_OUT_OF_RANGE` (50005) | 400 | 市场 PM 比例不在 [0.40, 0.65]，研发 PM 比例不在 [0.35, 0.60] |
| `CONTRIB_DIM_SUM_NOT_100` (50006) | 400 | 五维度权重和不等于 100（±0.01 容差） |
| `CONTRIB_NOT_G5_STAGE` (50007) | 409 | 项目不在 G5 上市后 90 天复盘阶段 |
| `CONTRIB_NOT_AUTHORIZED` (50008) | 403 | 评定人非双 PM 自评 / 非各自产品组长 |

## 8. 与 ZK-IPD §三.2.5 tierCoefficient 公式的一致性

本卡落地后，`tierCoefficient` 字段（即五维度修正因子）由 `ContributionService` 计算并落库，
供 `BonusPoolService.calculateBonusPoolByZkFormulaWithModifiers(pool, levelCoeff, tierCoeff, personalCoeff)` 读取，
满足 ZK-IPD §三.2.5"奖金可叠加销售达成率阶梯系数、个人绩效系数"的完整 4 因子叠加。
