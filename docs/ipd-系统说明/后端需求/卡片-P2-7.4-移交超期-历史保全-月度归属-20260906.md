# P2-7.4 移交超期、历史保全与月度归属（2026-09-06）

## 接口/逻辑设计

| 入口 | 路径/方法 | 权限码 | 说明 |
|---|---|---|---|
| Service | `HandoverService.scanOverdueDrafts(actor)` | `ipd:handover:write` | 扫描 DRAFT 超期（>7 天）的移交，自动作废或升级 |
| Service | `HandoverService.archiveCompletedHandover(handoverId, actor)` | `ipd:handover:read` | 归档已 COMPLETED 移交，写历史保全 |
| Service | `HandoverService.getMonthlyAttribution(projectId, month, actor)` | `ipd:handover:read` | 月度归属查询（按月在任 PM 列表） |
| Controller | `POST /api/v1/handovers/scan-overdue` | 同上 | OPS-04 调度入口 |
| Controller | `GET /api/v1/handovers/monthly-attribution/{projectId}` | 同上 | UI 月度报表 |

## 字段定义

- **scanOverdueDrafts 输入**：operator（系统/SUPER_ADMIN）
- **超期判定**：
  - `now - handover.createTime > 7 days` 且 status=DRAFT ⇒ 候选
  - 处置：
    - **轻量作废**：toPersonId 不在任（离职/DISABLED）⇒ status=EXPIRED_AUTO_VOID，审计 `HANDOVER_EXPIRED_VOID`
    - **升级通知**：toPersonId 在任但未签 ⇒ notification.publish type=HANDOVER_OVERDUE_ESCALATION（升级到组长）
- **archiveCompletedHandover 输入**：handoverId Long
- **归档语义**：
  - 不删 handover_records（AC-HIST-01：历史保全）
  - 写 audit_log：`HANDOVER_ARCHIVED`，附带完整 JSON 快照
  - 加标记字段 archived_at（TIMESTAMP，可空）
- **getMonthlyAttribution 输入**：
  - `projectId` Long
  - `month` String (yyyy-MM)
  - 返回 `List<MonthlyAttributionView>`：
    - `personId` / `personName` / `role`
    - `fromDate` / `toDate` / `daysInRole`
    - `source`: "BINDING"（在任绑定起止） / "TRANSFER"（移交起止）
- **幂等**：
  - scanOverdueDrafts 同一天对同一 handoverId 只产出一条审计/通知（dedup_key=HANDOVER_OVERDUE:handoverId:yyyyMMdd）
  - archiveCompletedHandover 重复调用直接跳过（archived_at 非空）

## 数据来源

- handover_records：status / fromPersonId / toPersonId / projectId / role / createTime / completedAt
- project_members：在任绑定表（已有）
- person：employmentStatus / accountStatus（在任判定）
- audit_log：归档历史

## 已知风险/限制

- 月度归属聚合需对 project_members.exit_date 做区间切片（增加 GROUP BY role）
- 归档后是否冻结 vs 软删除的语义需统一（当前 AC-HIST-01 是软归档 = 加 archived_at 标记）
- 超期 7 天的阈值建议可在 sys_config 配 `handover.draft.expire_days`（默认 7）
