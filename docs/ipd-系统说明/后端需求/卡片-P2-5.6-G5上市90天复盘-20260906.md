# P2-5.6 G5 上市 90 天复盘待办与日期变更重排（2026-09-06）

## 接口/逻辑设计

| 入口 | 路径/方法 | 权限码 | 说明 |
|---|---|---|---|
| Service | `PostLaunchReviewService.scheduleReview(projectId, launchDate, actor)` | `ipd:gate:write` | G5 通过后 90 天复盘待办自动生成 |
| Service | `PostLaunchReviewService.completeReview(projectId, reviewData, actor)` | `ipd:gate:write` | 完成复盘 + 写 KPI/奖金池台账 |
| Service | `LaunchDateChangeService.changeLaunchDate(projectId, newDate, reason, actor)` | `ipd:gate:write` | 上市日期变更 → 重排下游 G3/G4/G5 截止 |
| Controller | `POST /api/v1/gate/post-launch-review/{projectId}` | 同上 | UI 对接入口 |

## 字段定义

- **scheduleReview 输入**：
  - `projectId` Long
  - `launchDate` LocalDate（G5 通过日期）
  - `actor` IpdActor（PM 或超管）
- **生成 PostLaunchReview**：
  - `id` 自增
  - `projectId` 必填
  - `scheduledAt = launchDate + 90 days`
  - `status = "PENDING"`
  - `assigneeId = project.createBy` (原 PM，移交后跟 ProjectMember 取主 PM)
  - 审计 `POST_LAUNCH_REVIEW_SCHEDULED`
- **completeReview 输入**：
  - `reviewData`: { actualRevenue, customerFeedback, kpiAchievement, lessons }
  - `status = "COMPLETED"`
  - `completedAt = now`
  - 联动：KPI 季度兑现 / BonusPoolService.markContributionWindow
- **changeLaunchDate 输入**：
  - `newDate` LocalDate（新上市日期）
  - `reason` String 必填（纳入）
  - **下游 gate 截止重排**：G3/G4/G5 全部 deadlineAt += (newDate - oldDate)
  - 审计 `LAUNCH_DATE_CHANGED` 携带 fromDate/toDate/affectedGateIds[]
  - **约束**：newDate 必须在今天 ≥30 天后（避免反复变更）；超管豁免

## 数据来源

- 新表 `post_launch_reviews`：
  ```sql
  CREATE TABLE post_launch_reviews (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    project_id BIGINT NOT NULL,
    scheduled_at DATE NOT NULL,
    status VARCHAR(16) NOT NULL,  -- PENDING/COMPLETED/OVERDUE
    assignee_id BIGINT NOT NULL,
    actual_revenue DECIMAL(18,2),
    customer_feedback TEXT,
    kpi_achievement TEXT,
    lessons TEXT,
    completed_at DATETIME,
    tenant_id VARCHAR(32),
    create_time DATETIME,
    update_time DATETIME
  );
  ```
- 新表 `launch_date_changes`：
  ```sql
  CREATE TABLE launch_date_changes (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    project_id BIGINT NOT NULL,
    from_date DATE NOT NULL,
    to_date DATE NOT NULL,
    reason VARCHAR(500) NOT NULL,
    operator_id BIGINT NOT NULL,
    affected_gate_ids VARCHAR(500),  -- 逗号分隔
    tenant_id VARCHAR(32),
    create_time DATETIME
  );
  ```
