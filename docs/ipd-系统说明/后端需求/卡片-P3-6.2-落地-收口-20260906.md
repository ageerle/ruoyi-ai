## 关键公式

```
tierCoefficient = (dim1×25 + dim2×25 + dim3×20 + dim4×20 + dim5×10) / 10000
                 = (五维度加权得分) / 10000
                 ∈ [0.00, 1.00]（落入 BonusPool 4 因子叠加）
```

## 与 ZK-IPD §三.2.5 一致性

- ✅ 五维度权重和 = 100（25+25+20+20+10）
- ✅ 市场 PM 比例 ∈ [0.40, 0.65]，研发联动 ∈ [0.35, 0.60]
- ✅ tierCoefficient ∈ [0.00, 1.00]，可作为 BonusPool 修正因子
- ✅ 入口仅 G5 阶段开放（AC-INC-28）
- ✅ 评定人 = 双 PM 自评 + 各自产品组长（无「评审上级」角色）
