## 1. 业务规则映射（ZK-IPD §X）

### 1.1 来源（ZK-IPD Prompt §三.2.5 / BR-INC-10）

四种触发情形 × 主责方 / 连带方映射（AC-INC-36b/37/38 + BR-INC-10）：

| 触发情形（triggerType） | 主责方（mainRole） | 连带方（relatedRole） |
|---|---|---|
| `REWORK_EXCEEDED` 需求返工率超标 | MARKET_PM | RD_PM |
| `QUALITY_ACCIDENT` 质量事故 | RD_PM | MARKET_PM |
| `SPEC_PILE_COPY` 参数堆砌 / 对标抄袭 | RD_PM | MARKET_PM |
| `MISSED_MARKET_WINDOW` 错过市场窗口 | **双 PM 共同**（无主责/连带区分） | — |

执行动作（**executionAction**）：

| 类型 | 含义 |
|---|---|
| `STOP_ALLOWANCE` | 主责方津贴**停发** |
| `HALVE_ALLOWANCE` | 连带方津贴**减半** |
| `BONUS_DOWNGRADE` | 贡献度系数降低（默认 -0.5） |
| `BONUS_DISQUALIFY` | 取消分配资格（`bonusEligible=false`） |

**双 PM 共同担责**（MISSED_MARKET_WINDOW）：market+rd 都触发 `STOP_ALLOWANCE`，
**无** 连带减半；AC-INC-38。

### 1.2 引用 AC

| AC | 预期 | 落点 |
|---|---|---|
| AC-INC-36b ⚠️ | 需求返工率超标 → 市场PM停发；研发PM减半 | `NegativeFeedbackService.applyReworkExceeded(...)` |
| AC-INC-37 | 质量事故 → 研发PM停发；市场PM减半 | `applyQualityAccident(...)` |
| AC-INC-38 | 错过市场窗口 → 双 PM 共同担责（无主责/连带） | `applyMissedMarketWindow(...)`（mainRole=BOTH） |
| AC-INC-39 | 负反馈对奖金的影响 → 贡献度系数降低或取消分配资格 | 落 `bonusEligible=0` + `tierDelta=-0.5` 到 `project_members` |
| AC-INC-40 ⚠️ | 负反馈执行记录完整写审计（触发情形/主责/连带/执行人） | `auditLogService.append(...)` |

### 1.3 引用 BR

- **BR-INC-10** 负反馈机制（四种触发情形 × 主责/连带映射）
- **BR-INC-12** 退出机制（连续两期 < 60 → 退出次月停发；本卡不实现，由 P3-8.3 接手）

### 1.4 状态机

```
DRAFT (草稿/录入)
  ↓ trigger
PENDING_DECISION (待认定)
  ↓ decision APPROVE
EXECUTED (已执行，停发/减半生效)
  ↓ recovery (PENALTY_LIFTED)
LIFTED (已解除，恢复津贴 + bonusEligible=true)
```

> 状态枚举：`DRAFT | PENDING_DECISION | EXECUTED | LIFTED | REJECTED`
> 触发后默认走 `PENDING_DECISION` → 组长确认 → `EXECUTED`；
> 若同一项目同 triggerType 已有 EXECUTED 记录：禁止重复扣减（**AC-INC-40 重复不重复扣**）。

## 2. API 契约

### 2.1 端点

| 方法 | 路径 | 说明 | 权限码 |
|---|---|---|---|
| POST | `/api/v1/negative-feedbacks` | 录入负反馈事件（DRAFT） | `ipd:negative-feedback:create` |
| PUT | `/api/v1/negative-feedbacks/{id}/submit` | 提交认定（DRAFT → PENDING_DECISION） | 同上 |
| PUT | `/api/v1/negative-feedbacks/{id}/decide` | 组长认定（PENDING_DECISION → EXECUTED） | `ipd:negative-feedback:decide` |
| PUT | `/api/v1/negative-feedbacks/{id}/lift` | 解除（EXECUTED → LIFTED，恢复 bonusEligible） | `ipd:negative-feedback:decide` |
| GET | `/api/v1/negative-feedbacks/{id}` | 详情 | `ipd:negative-feedback:query` |
| GET | `/api/v1/negative-feedbacks` | 列表（按 projectId + status） | 同上 |
| GET | `/api/v1/negative-feedbacks/by-project/{projectId}/effective` | 当前生效中（EXECUTED 且未解除） | 同上 |

## 5. 测试矩阵（6 维度）

| 维度 | 用例 |
|---|---|
| 正常路径 | 需求返工率超标 → MARKET_PM停发 + RD_PM减半 + bonusDisqualify=true + tierDelta=-0.5 |
| 边界 | 错过市场窗口 → BOTH → MARKET_PM + RD_PM 都 STOP_ALLOWANCE，无 related |
| 异常 | triggerType 非法 / triggerMonth 格式错 / 项目无 PM |
| 权限 | GROUP_LEADER decide / SUPER_ADMIN decide；MARKET_PM decide → 403 |
| 审计 | submit + decide + lift 各落 1 条 audit_log（含 triggerType / 角色映射 / 执行人） |
| 幂等 | 同项目同 triggerType 已 EXECUTED → 重提报 NF_REENTRY_NOT_ALLOWED |

## 6. 安全审查点

| 项 | 措施 |
|---|---|
| 横向越权 | decide/lift 仅 GROUP_LEADER / SUPER_ADMIN；create 走 requireInternal |
| 多租户 | BaseEntity 自动按 tenantId 过滤 |
| 状态机 | EXECUTED 不可再 decide；DRAFT 不可直接 lift |
| 幂等防重 | uk_nf_project_trigger_active 唯一索引 + service 二次校验 |
| 审计 | decide/lift 必落 audit_log（triggerType/mainRole/relatedRole/mainExecution/relatedExecution） |
| 通知联动 | decide 后向双 PM 发 ACTION 通知，lift 后发 FYI 通知 |

## 8. 与上下游卡的联动

- **P3-8.1 负反馈四类触发与责任评定**：本卡是 P3-8.1 评定结果的执行段（decide 端点接收 P3-8.1 评定主责/连带映射）。
