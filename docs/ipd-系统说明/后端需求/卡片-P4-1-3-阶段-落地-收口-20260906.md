### `service/GuestDemandService.java`（untracked）— P4-1.2 + P4-1.3 扩展

新增 4 个公开方法：

```java
@Transactional(readOnly = true)
public GuestDemandView queryByCode(String queryCode);                      // P4-1.2 AC-REQ-04

@Transactional(rollbackFor = Exception.class)
public GuestDemandView supplement(String queryCode, GuestDemandUpdateReq req, ...); // P4-1.2 AC-REQ-04

@Transactional(rollbackFor = Exception.class)
public GuestDemandView withdraw(String queryCode, GuestDemandUpdateReq req, ...);   // P4-1.2 AC-REQ-04b

@Transactional(rollbackFor = Exception.class)
public GuestDemandView routeDualPm(String queryCode);                      // P4-1.3 AC-REQ-03

@Transactional(rollbackFor = Exception.class)
public int notifyOverdueUnassigned();                                      // P4-1.3 AC-PROD-09
```

业务规则：

- **BR-REQ-03**：查询码查询仅返回 queryCode + 状态 + 路由时间 + 标题摘要；不暴露内部 ID / 人员 / 备注
- **BR-REQ-03a**：受理后（status ≠ SUBMITTED）禁止再改原文，仅可评论
- **BR-REQ-03b**：仅 SUBMITTED 可撤回；撤回置 WITHDRAWN 终态
- **BR-REQ-04**：产品 1:1 项目（uk_products_project），取该项目在职 MARKET_PM/RD_PM 写双 PM
- **BR-REQ-04a**：submitedAt + 5 个工作日（跳过周末）后未处理，通知超管
- **并发守卫**：`routeDualPm` 用条件 UPDATE 守卫（仅 SUBMITTED/UNASSIGNED 才更新双 PM），避免并发双路由
