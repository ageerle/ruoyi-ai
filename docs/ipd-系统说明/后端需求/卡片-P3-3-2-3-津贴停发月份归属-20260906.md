## 三、本卡新增 Service 方法

### P3-3.2 停发判定

```
public String determineLowScoreStop(BigDecimal comprehensiveScore)
  score < 60  ⇒ "STOP_SCORE_BELOW_60"
  score == 60 ⇒ null（含）
  score == null ⇒ null（无证据不发）

public String determineNoOutput60DaysStop(Date lastActivityDate, Date asOfDate, boolean isAdditionalProject)
  isAdditionalProject=false ⇒ null（AC-INC-08 主项目无产出不触发）
  lastActivityDate=null ⇒ "STOP_NO_OUTPUT_60_DAYS"
  days >= 60 ⇒ "STOP_NO_OUTPUT_60_DAYS"

public String determineStopReasonP332(BigDecimal score, Date last, Date asOf, boolean isAdditional)
  三层合一：主项目无产出⇒null；绩效<60⇒STOP_SCORE_BELOW_60；60天无产出⇒STOP_NO_OUTPUT_60_DAYS
```

### P3-3.3 月份归属

```
public boolean existsByKey(Long personId, Long projectId, String month)
  (personId, projectId, month) 唯一

public boolean isMemberEffectiveInMonth(Date joinDate, String month)
  joinDate >= monthStart ⇒ false（新人次月生效）
  joinDate < monthStart  ⇒ true

public boolean isMemberActiveInMonth(Date exitDate, String month)
  exitDate == null       ⇒ true
  exitDate >= monthStart ⇒ true（当月退当月仍计）
  exitDate <  monthStart ⇒ false（次月已停）

public boolean isMemberActiveForMonth(ProjectMember m, String month)
  综合判定：未退出+已加入 ⇒ active

@Transactional
public AllowanceLedger idempotentInsert(AllowanceLedger ledger)
  并发重算护栏：已存在 ⇒ 返回 null，不写第二条
```
