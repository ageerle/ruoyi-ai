## 三、本卡新增 Service 方法

### P3-4.2 配置校验

```
public static void validatePoolRate(BigDecimal poolRate)
  null ⇒ 走默认；0 < rate ≤ 1；精度 ≤ 4 位小数（BR-INC-04）

public static void validateProjectCoefficient(String projectLevel, BigDecimal coefficient)
  S: 1.5 ≤ coef ≤ 2.0；A: coef == 1.0；B: 0.6 ≤ coef ≤ 0.8（BR-INC-05）

public BigDecimal readActivePoolRate()
  实时读 poolRate 配置（当前硬编码 0.0500，P0-3.3 完成后由 SystemConfigService 接管）

public BigDecimal calculateBasePoolConfigurable(BigDecimal targetSales)
  basePool = targetSales × poolRate（实时读 + 2 位 HALF_UP 舍入）

public BigDecimal calculateBasePoolWithRate(BigDecimal targetSales, BigDecimal poolRate)
  basePool = targetSales × poolRate（入参 poolRate，校验后计算）

public BigDecimal getDefaultCoefficientFor(String projectLevel)
  S → 1.8；A → 1.0；B → 0.7；其他等级抛异常
```

### P3-4.5 项目绩效系数分档

```
public BigDecimal projectPerformanceCoefficient(BigDecimal comprehensiveScore)
  score ≥ 95 ⇒ 1.0（AC-INC-22：96 分 ⇒ 1.0）
  score ≥ 85 ⇒ 0.8（AC-INC-23：88 分 ⇒ 0.8）
  score ≥ 70 ⇒ 0.6
  score ≥ 60 ⇒ 0.3
  score < 60 ⇒ 0（AC-INC-24：55 分 ⇒ 0，取消奖金资格）

public static void validateProjectPerfStrategy(String strategy)
  PROJECT_SCORE / WEIGHTED_AVG / LAST_QUARTER（BR-INC-07）

public static void assertAbilityLevelNotUsedAsCoefficient(String abilityLevel)
  abilityLevel 传入但不参与系数计算（AC-INC-22b 能力等级不得代替项目绩效）
```

## 六、安全审查点

| 项 | 措施 |
|---|---|
| 横向越权 | 走 `requireInternal()`（继承 P3-4.4 权限） |
| SQL 注入 | 仅 `LambdaQueryWrapper.eq()`，无字符串拼 |
| 多租户 | BaseEntity 自带 tenantId 过滤 |
| 配置版本 | `readActivePoolRate` 实时读，配置变更立即生效（无缓存） |
| Decimal 精度 | poolRate 校验 scale ≤ 4；计算结果 HALF_UP 2 位小数 |
| 能力等级隔离 | `assertAbilityLevelNotUsedAsCoefficient` 显式断言系数不由 L1~L5 推导 |
