## 2. API 契约

### 2.1 端点：`POST /api/v1/bonus-pool/compute`

| 项 | 值 |
|---|---|
| 路径 | `POST /api/v1/bonus-pool/compute` |
| 权限码 | `ipd:bonus-pool:compute`（MARKET_PM / RD_PM / GROUP_LEADER / SUPER_ADMIN） |
| 入参 DTO | `ComputeBonusPoolReq` |
| 出参 | `ApiV1Response<BonusPool>` |

**请求体**：

```java
public record ComputeBonusPoolReq(
    @NotNull Long projectId,                  // 项目 ID
    @NotNull @DecimalMin("0") BigDecimal actualReceipts,  // 实际回款金额（≥0）
    @DecimalMin("0") BigDecimal achievementRate,         // 销售达成率 %（可空=中性）
    @DecimalMin("0") BigDecimal personalCoefficient,     // 个人绩效系数（可空=1.0）
    @DecimalMin("0") BigDecimal poolRate                 // 奖金池比例（可空=0.05）
) { }
```

**响应**：`BonusPool` 实体（id 已生成，status=DRAFT，finalPool 已按 §三.2.5 完整公式计算）。

### 2.2 端点：`POST /api/v1/bonus-pool/{id}/freeze`

| 项 | 值 |
|---|---|
| 路径 | `POST /api/v1/bonus-pool/{id}/freeze` |
| 权限码 | `ipd:bonus-pool:freeze`（GROUP_LEADER / SUPER_ADMIN，涉钱审批） |
| 入参 | 路径变量 `id`；body 可选 `{reason}` |
| 出参 | `ApiV1Response<BonusPool>` |

**状态流转**：DRAFT → CONFIRMED；幂等（同状态返回当前实体，不写审计）。

### 2.3 端点：`POST /api/v1/bonus-pool/{id}/distribute`

| 项 | 值 |
|---|---|
| 路径 | `POST /api/v1/bonus-pool/{id}/distribute` |
| 权限码 | `ipd:bonus-pool:distribute`（GROUP_LEADER / SUPER_ADMIN，涉钱分配） |
| 入参 DTO | `DistributeBonusPoolReq` |
| 出参 | `ApiV1Response<BonusPool>` |

**请求体**：

```java
public record DistributeBonusPoolReq(
    @NotNull @DecimalMin("0.40") @DecimalMax("0.65") BigDecimal marketShare,
    @NotNull @DecimalMin("0.35") @DecimalMax("0.60") BigDecimal rdShare
) { }
```

**业务规则**：调用 `BonusPoolService.applyDistribution(pool.finalPool, marketShare, rdShare)`；区间+总和双重校验由 Service 内承担；status DRAFT/CONFIRMED → DISTRIBUTED；幂等（DISTRIBUTED 返回当前实体，不重写审计）。

**响应字段**：`marketAmount`、`rdAmount` 落入 `distributions` JSON。

### 2.4 端点：`GET /api/v1/bonus-pool/{id}`

| 项 | 值 |
|---|---|
| 路径 | `GET /api/v1/bonus-pool/{id}` |
| 权限码 | `ipd:bonus-pool:query`（MARKET_PM / RD_PM / GROUP_LEADER / SUPER_ADMIN） |
| 入参 | 路径变量 `id` |
| 出参 | `ApiV1Response<BonusPool>` |

**业务规则**：不存在 → `NOT_FOUND`；已软删（del_flag=1）→ `NOT_FOUND`。

### 2.5 端点：`GET /api/v1/bonus-pool/list`

| 项 | 值 |
|---|---|
| 路径 | `GET /api/v1/bonus-pool/list` |
| 权限码 | `ipd:bonus-pool:query` |
| 入参 | `projectId`（必填） |
| 出参 | `ApiV1Response<List<BonusPool>>` |

**业务规则**：按 `projectId` 过滤 + `del_flag=0` + `orderByDesc(calculatedAt)`。

### 2.6 错误码

| 场景 | 错误码 | HTTP |
|---|---|---|
| 参数缺失/格式错 | `PARAM_INVALID` | 400 |
| 项目不存在 / 项目无 levelCoefficient | `NOT_FOUND`（项目）/ `PARAM_INVALID`（系数） | 404 / 400 |
| 奖金池不存在 | `NOT_FOUND` | 404 |
| 状态非法（DISTRIBUTED 不可 freeze） | `STATE_CONFLICT` | 409 |
| 分配比例越界（market ∉ [40%, 65%]） | `PARAM_INVALID`（ServiceException 透传） | 400 |
| 权限不足 | `FORBIDDEN` | 403 |
| 未登录 | `UNAUTHORIZED` | 401 |

## 5. 测试矩阵（6 维度）

| 维度 | 用例 |
|---|---|
| 正常路径 | compute 完整公式 4 因子叠加 → 返回 DRAFT BonusPool；freeze 状态流转；distribute 比例拆分 |
| 边界 | achievementRate=100/personalCoefficient=null/actualReceipts=0 → finalPool=0；DISTRIBUTED 不可再 freeze 抛 STATE_CONFLICT |
| 异常 | projectId 不存在 → NOT_FOUND；marketShare<0.40 → IpdBusinessException；actualReceipts<0 → IpdBusinessException |
| 权限 | MARKET_PM 调 freeze → FORBIDDEN；RD_PM 调 distribute → FORBIDDEN |
| 审计 | freeze / distribute 各落 1 条 audit_log（仅 ① 不写 before_data，② after_data 含 status 流转） |
| 幂等 | 同状态再调 freeze / distribute 不写第二条审计；DISTRIBUTED 再调 distribute 不抛错，返回当前实体 |

## 6. 安全审查点

| 项 | 措施 |
|---|---|
| 横向越权 | `compute / query / list` 走 `requireInternal()`；`freeze / distribute` 走 `requireLeaderOrAdmin()`（GROUP_LEADER + SUPER_ADMIN 双签） |
| SQL 注入 | 仅用 `LambdaQueryWrapper.eq(BonusPool::getProjectId, projectId)`，无字符串拼 |
| 多租户 | `BaseEntity` 自动按 `tenantId` 过滤；与项目域绑定，跨组查询由 `canAccessGroup` 兜底（freeze/distribute 当前用 GROUP_LEADER_OR_ADMIN 双重护栏） |
| 审计 | freeze / distribute 必落 1 条 audit_log（write 动作）；compute / query 不落审计 |
| 限流 | `@RateLimiter` 不上（涉钱类操作低频） |
| 状态机 | DISTRIBUTED 是终态；CONFIRMED → DISTRIBUTED 单向；DRAFT → CONFIRMED/DISTRIBUTED 单向 |
