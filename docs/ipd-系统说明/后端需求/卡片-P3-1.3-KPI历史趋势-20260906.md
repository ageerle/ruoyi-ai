# 卡片 P3-1.3 — KPI 截止日、催办与导入分段（2026-09-06）

> 修正既有“历史趋势”偏离业务卡的问题。本卡实现次月第 N 个工作日 18:00 截止、
> 逾期第 1/3 天提醒升级，以及功能/共担 KPI 的在研分段规则。

## 1. 业务规则映射

| 规则 | 口径 | 实现 |
|---|---|---|
| AC-KPI-21 | 次月第 5 个工作日 18:00；逾期第 1 天提醒组长、第 3 天升级超管 | `resolveMonthlyDeadline` + `scanMonthlyDeadlines` |
| AC-KPI-21b | `kpi.monthlyDeadlineDay=10` 即时切换为次月第 10 个工作日 | 读 `SystemConfigService` 缓存，写穿透生效 |
| BR-KPI-05 | 共担月度归集由产品组长负责 | day1 收件人按 `product_groups.leader_person_id` |
| BR-KPI-07 | 功能补入后全量，共担全量不分段 | `segment=FULL` / `FULL_SHARED`，不按在研阶段自动关闭/折算 |
| 幂等 | 重复扫描不重复提醒 | `NotificationService` receiver 级 `dedup_key` |
| 生命周期 | 逾期不自动关闭任务 | P3-1.3 只通知，不写 KpiRecord 状态 |

## 2. API 契约

### 2.1 `POST /api/v1/kpi/shared/deadline-scan`

- 仅超管可手动触发。
- `period`：被归集月份，例如 `2026-08`；截止日按次月计算。
- 扫描日期默认系统当前日，Service 暴露 `scanMonthlyDeadlines(LocalDate,YearMonth,int)` 便于定时任务与测试。
- 响应 `DeadlineScanResult(day1Reminders,day3Escalations,skippedProjects)`。
- 未到截止日返回 0/0/0；没有 `FINALIZED` 共担记录才进入提醒分支。

### 2.2 计算边界

`resolveMonthlyDeadline` 从次月 1 日顺序跳过周六/周日，命中第 N 个工作日后固定返回 `18:00`。
例：2026-09 的第 5 个工作日是 2026-09-07 18:00；第 10 个工作日是 2026-09-14 18:00。
业务日不硬编码为自然日 5/10。

## 3. 数据库变更

**无新增表**：复用 `kpi_records`、`projects`、`project_members`、`persons`、`product_groups`、
`system_configs` 与 `notification_events`。

- P3-1.2 负责为 `kpi_records` 增加 `revision` 唯一索引。
- `kpi.monthlyDeadlineDay` 已有种子 `5`，由 `SystemConfigService.update` 写穿透失效。
- 通知 outbox 的唯一键为 `source_type:event_type:source_id:receiver_id`，扫描重复不会生成新提醒事件。

## 4. 复用清单

- `SystemConfigService.getIntValue` + `invalidate` 写穿透参数缓存。
- `ProjectMapper / ProjectMemberMapper / PersonMapper / ProductGroupMapper` 获取项目、双 PM、组长。
- `KpiRecordMapper.selectCount` 检查 `FINALIZED` 归集。
- `NotificationService.publish` + `AuditLogService.append`。
- `KpiRecord.revision` 与 `segment` 保持追加版本。
- LambdaQueryWrapper 全部使用参数化条件，不拼接用户值。

## 6. 安全审查点

- 提醒收件人只来自产品组 leader 关系，不接受请求体传入 leaderId。
- 超管名单由 `persons.person_type=SUPER_ADMIN` 读取；普通 PM 永远不能发超管升级。
- 通知不包含敏感明细，仅含项目、周期、逾期天数。
- 写入审计操作人固定为系统通道 `0/PROJECT_DEADLINE_SCANNER`。
- 缺数只提醒，不自动补写/关闭；避免把“未归集”误判为 0 分。
