# P2-5.5 Gate 结果回写阶段与 G3 滚动风险（2026-09-06）

## 接口/逻辑设计

| 入口 | 路径/方法 | 权限码 | 说明 |
|---|---|---|---|
| Service | `GateReviewService.applyQualifiedResult(gateId, actor)` | `ipd:gate:write` | 合规结果（双 APPROVE）回写到 project.currentStage，触发阶段推进 |
| Service | `GateReviewService.rejectInferiorResult(gateId, reason, actor)` | 同上 | 否决/遗留（任 REJECT / 双弃权）拒绝推进，落驳回审计 |
| Service | `GateReviewService.applyG3RollingRiskUpdate(gateId, riskLevel, actor)` | `ipd:gate:write` | G3 滚动风险评估（每 2 周），超管触发升级通知 |
| Service | `GateReviewService.isAdvanceCallback(gateId, actor)` | — | 重复回调幂等判定（同 gateId 已 advance ⇒ 不二次推进） |

## 字段定义

- **applyQualifiedResult 输入**：`gateId` Long + `actor` IpdActor
- **回写语义**：
  - gate.result == "APPROVED" (双 PM 已签)
  - project.currentStage = gate.targetStage (如 G2→CONCEPT_REVIEW_DONE, G3→PLAN_REVIEW_DONE)
  - 同步 project.gateId 滚动到下一个 gate (nextStageGate)
  - 审计 `GATE_QUALIFIED_ADVANCE` 携带 fromStage/toStage/roundNo
- **rejectInferiorResult 输入**：
  - `reason` String（必填，纳入审计）
  - 拒绝推进，保持 currentStage 不动
  - 审计 `GATE_INFERIOR_REJECT`
- **G3 滚动风险**：
  - `riskLevel`: LOW/MEDIUM/HIGH/CRITICAL
  - HIGH/CRITICAL 升级到超管（notification.publish，type=G3_RISK_ESCALATION）
  - 审计 `G3_ROLLING_RISK_UPDATE`
- **幂等 (isAdvanceCallback)**：
  - 查 audit_log 表：同 gateId + action=GATE_QUALIFIED_ADVANCE 已有 ⇒ true
  - 用于防止重复回调（KPI 计算/对账轮询都可能触发）

## AC 引用

- AC-GATE-22：只有合格结果推进阶段（双 APPROVE ⇒ currentStage +1）
- AC-GATE-23：否决/遗留拒绝推进（任 REJECT 或双 ABSTAIN ⇒ 不推进）
- AC-GATE-24：G3 双周滚动 + 风险升级（HIGH/CRITICAL 自动通知超管）
- AC-GATE-25：重复回调不二次推进（幂等保护）

## 复用清单

| 能力 | 复用方式 |
|---|---|
| 推进逻辑 | ProjectService.advanceStage（已具备，写 project.currentStage） |
| 审计 | AuditLogService.append |
| 通知 | NotificationService.publish(type=G3_RISK_ESCALATION) |
| 幂等查 | AuditLogService.listByActionAndEntity |
| 弃权行 | GateReviewService.abstainForReviewer |
| 阶段映射 | ProjectStage enum / Gate.targetStage |

## 数据来源

- gate_reviews：取最新 2 条（同 gateId，order by signedAt desc）
- project：currentStage, gateId（当前 gate），mainGroupId
- gate：targetStage, type=G3, deadlineAt, extendTimes
- audit_log：查幂等键（GATE_QUALIFIED_ADVANCE + gateId）

## 已知风险/限制

- 阶段推进的原子性依赖 ProjectService.advanceStage 的行锁（已具备）
- G3 滚动风险的双周调度依赖 OPS-04（待闭环）
- 重复回调幂等需要 audit_log 表索引覆盖（entity_type + entity_id + action）
