## 2. 业务规则（ZK-IPD §三.2.6）

| BR 编码 | 规则 | 落地位置 |
|---|---|---|
| BR-WB-01 | 项目可见范围：SUPER_ADMIN = 全部 ACTIVE 项目；其他 = `project_members` 当前人数组 | `WorkbenchService.visibleProjects` |
| BR-WB-02 | OPEN_STATUSES = {NOT_STARTED, IN_PROGRESS, DELAYED}（P1-4.3：DELAYED 仅深管存在，统一计入待办） | `WorkbenchService.OPEN_STATUSES` |
| BR-WB-03 | 责任匹配：ownerRole ∈ {MARKET_PM, RD_PM} 定向该角色；BOTH / JOINT / 空值 = 全员可见；组长/超管看全部 | `WorkbenchService.isMine` |
| BR-WB-04 | 逾期判定：dueDate != null && dueDate < now → priority=high | `summary` 循环内 |
| BR-WB-05 | 当前推进 = 指定项目（或第一个可见项目）当前阶段首个未完成动作（OPEN_STATUSES ∩ isMine） | `WorkbenchService.currentAdvance` |
| BR-WB-06 | 删除审批待办：组长 = LEADER_REVIEW 数；超管 = ADMIN_REVIEW 数；其他角色 0 | `WorkbenchService.deletionPendingCount` |
| BR-WB-07 | 计数一律 int 装箱（避免 Long→String 全局序列化破坏 number 契约） | service:107-109 |
