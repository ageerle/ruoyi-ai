## 一、CI 静态检查脚本（修正路径版）

`docs/开发说明/开发说明书.md` 附录 A 提供了 grep 检查命令，但路径 `src/` `apps/` 在本仓库不存在。本文件提供**本仓库实际路径**的修正版。

### 1.1 涉钱硬编码检查

```bash
# 修正版：本仓库源码在 ruoyi-*/src/main/java/
# 必须输出 0 命中

grep -rn "equalityTolerance" \
  ruoyi-modules/ ruoyi-admin/src/ ruoyi-common/ \
  --include="*.java" --include="*.kt" --include="*.ts" --include="*.vue"

grep -rnE "=== ?100(\.0+)?[^0-9]" \
  ruoyi-modules/ ruoyi-admin/src/ ruoyi-common/ \
  --include="*.java" --include="*.kt" --include="*.ts" --include="*.vue"

grep -rnE "toFixed\(2\) ?== ?" \
  ruoyi-modules/ ruoyi-admin/src/ ruoyi-common/ \
  --include="*.java" --include="*.kt" --include="*.ts" --include="*.vue"
```

### 1.2 跨角色硬编码检查（G-09）

```bash
grep -rnE "(评审上级|代理组长|代审人|委托审批)" \
```


### 1.7 成功响应码（新 IPD 接口 code=0，老接口 code=200）


```bash

grep -n "enabled:" ruoyi-admin/src/main/resources/application-prod.yml | grep demo
# 生产 profile 必须 demo.enabled=false
```

## 二、CI 集成（GitHub Actions）

新建 `.github/workflows/ipd-migration-check.yml`（不覆盖现有 wiki-lint.yml）：

```yaml
name: ipd-migration-check

on:
  push:
    paths:
      - 'ruoyi-admin/src/main/java/org/ruoyi/admin/controller/api/v1/**'
      - 'docs/ipd-系统说明/**'
      - '.github/workflows/ipd-migration-check.yml'
  pull_request:
    paths:
      - 'ruoyi-admin/src/main/java/org/ruoyi/admin/controller/api/v1/**'
      - 'docs/ipd-系统说明/**'

jobs:
  ipd-checks:
    name: ipd-migration-check
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: 涉钱硬编码检查
        run: |
          grep -rn "equalityTolerance" \
            ruoyi-modules/ ruoyi-admin/src/ ruoyi-common/ \
            --include="*.java" --include="*.kt" --include="*.ts" --include="*.vue" \
            && { echo '❌ equalityTolerance found'; exit 1; } || echo '✅ clean'

      - name: 跨角色硬编码检查
        run: |
          grep -rnE "(评审上级|代理组长|代审人|委托审批)" \
            ruoyi-modules/ ruoyi-admin/src/ \
            --include="*.java" --include="*.kt" --include="*.vue" \
            | grep -v "禁止\|不实现\|不允许" \
            && { echo '❌ 跨角色硬编码'; exit 1; } || echo '✅ clean'

      - name: 直接删除入口检查
        run: |
          grep -rnE "(?<!软)\bdelete(All|ById)?\(" \
            ruoyi-admin/src/main/java/org/ruoyi/admin/controller/api/v1/ \
            --include="*.java" \
            && { echo '❌ 禁止直接删除'; exit 1; } || echo '✅ clean'

      - name: API 路径前缀检查（新接口必须 /api/v1）
        run: |
          grep -rnE "@(Get|Post|Put|Delete|Patch)Mapping\(['\"]/" \
            ruoyi-admin/src/main/java/org/ruoyi/admin/controller/api/v1/ \
            --include="*.java" \
            | grep -v "/api/v1/" \
            && { echo '❌ 新 IPD 接口必须以 /api/v1/ 开头'; exit 1; } || echo '✅ clean'
```

## 三、人工检查 checklist（提交 PR 前必跑）

### 3.1 新增 IPD 业务表前

- [ ] 查 [`type-mapping.md`](type-mapping.md) 确认字段类型映射
- [ ] 查 [`naming-convention.md`](naming-convention.md) 确认表名 / 字段名风格
- [ ] 在 entity 加 `@TableName("...")` 用文档原名（如 `persons`、`projects`）
- [ ] 主键 `@TableId(type = =IdType.ASSIGN_ID)`（雪花）
- [ ] 加 `BaseEntity` 公共字段（id / createTime / updateTime / createBy / updateBy / delFlag / tenantId / remark）
- [ ] mapper 继承 `BaseMapper<Xxx>`，复杂查询写 XML（resources/mapper/...）
- [ ] 加 `system_configs` 配置项（如该表需要可配置参数）
- [ ] 加 `tenant.excludes` 共享表登记（如该表跨租户共享）
- [ ] service 加 `@Audit` 注解（写操作）

### 3.2 新增 IPD controller 前

- [ ] 路径在 `/api/v1/...` 前缀下
- [ ] 返回类型用 `ApiV1Response<T>`（不混用 `R<T>`）
- [ ] 错误码参考 [`drift-audit-report.md §B.1.2`](drift-audit-report.md)
- [ ] `@SaCheckPermission("ipd:xxx:list")` 权限注解
- [ ] `@SaCheckDataScope` 数据权限范围（如涉及 PM 数据隔离）
- [ ] 跨角色检查（G-09）：不引入"评审上级""代理组长"等新角色
- [ ] 接口文档（Springdoc `@Operation`）

### 3.3 涉钱逻辑修改前

- [ ] 6 项强制可切换参数全部走 `system_configs`（G-08）
- [ ] 不用 `===` 不用 `==` 比浮点
- [ ] 4 个奖金算例必过（开发说明书 §8.4）
- [ ] 写 JUnit 测试（`@Tag("dev")`）
- [ ] 多项目津贴叠加 ≤ 当前评级 × 2（BR-INC-03）

### 3.4 审计相关修改前

- [ ] 写入走 `@Audit` 切面
- [ ] DB 层 REVOKE UPDATE / DELETE（运维脚本）
- [ ] 不修改历史记录（BR-AUD-02）
- [ ] hash 链验证（开发说明书 §12.1）
- [ ] 分层导出范围正确（BR-AUD-03）
