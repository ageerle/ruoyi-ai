## 推荐方案（方案 A）

### 步骤 1：差集审计（不阻塞业务）
```sql
-- 找出库级 INSERT 兜底而表级未登记的表
SELECT t.table_name, 'NO_TABLE_INSERT_GRANT' AS issue
FROM information_schema.tables t
WHERE t.table_schema = 'ipd_dev'
  AND t.table_name NOT IN (
    SELECT table_name FROM mysql.tables_priv
    WHERE user = 'ipd_app' AND host = '127.0.0.1' AND db = 'ipd_dev'
      AND privilege_type = 'Insert'
  );
```

### 步骤 2：仅对 4 张核心表 REVOKE 库级 INSERT
```sql
REVOKE INSERT ON ipd_dev.persons FROM 'ipd_app'@'127.0.0.1';
REVOKE INSERT ON ipd_dev.projects FROM 'ipd_app'@'127.0.0.1';
REVOKE INSERT ON ipd_dev.requirements FROM 'ipd_app'@'127.0.0.1';
-- audit_logs + audit_log_chain_heads 保持表级 GRANT（应用业务需求）
```
