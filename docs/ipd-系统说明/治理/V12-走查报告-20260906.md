### 2.2 缺失（关键真问题）
**`layouts/ipd.vue:344-625` 的 IPD Shell CSS 完全硬编码色值**，未走 html.dark：
- `.ipd-app` 直写 `#f5f7fb` 背景、`#172033` 文字（line 354-359）
- `.topbar` 直写 `background: var(--navy)` 而 `--navy` 在 `.ipd-app` 内重定义为 `#071426`（line 346）
- `.sidebar` 直写 `background: var(--navy-2) = #18253a`
- `.stage-rail` 直写 `background: white`、`border-bottom: 1px solid var(--line)`
- `.global-ai-entry` 直写渐变 `#2f6bff → #6b5cff`
- `.create-modal` 直写 `background: white`、`box-shadow: rgb(9 18 33 / 0.3)`

→ **暗色模式下**：topbar / sidebar / stage-rail / 弹窗全部仍是浅蓝白底，V11 暗色只在 ipd-theme.css 范围内生效，**布局层失效**。

### 2.3 优先级（按视觉占比排序）
1. **顶栏 topbar（#071426 → #0d1b2a）+ sidebar（#18253a → #1b2a41）**——最高频全屏元素
2. **stage-rail / .create-modal 卡片白底**——中间灰阶
3. **main-area 背景 + 文字色**——次要
4. **全局 AI 入口按钮渐变**——视觉点缀，可最后改

### 2.4 触发机制（暗色开关在哪儿）
- `internal/tailwind-config/src/index.ts:125` 设 `darkMode: 'selector'`（即 `.dark` 类）
- `internal/tailwind-config/src/index.ts:133` safelist 含 `'dark'`
- 但 IPD 仓**未发现 `useDark()` 调用方**——暗色切换入口继承自 Vben 全局偏好（preferences），IPD 页面无独立开关。
