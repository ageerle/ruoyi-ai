## 三、跨会话协作铁律（vibe-kanban HTTP API）

```bash
# 写：MCP 断时**禁止**用 mcp__zker_vibe_kanban__update_task（静默失败）
curl -X PUT -H "Content-Type: application/json" \
  -d '{"status":"done"}' \
  "http://127.0.0.1:62250/api/tasks/<uuid>"

# 二次读验证
curl -s "http://127.0.0.1:62250/api/tasks/<uuid>" | jq .data.status
```

**限制**：
- PATCH / POST 均 405（vibe-kanban 唯一支持 PUT）
- PUT 后 `updated_at` 字段不更新（依赖时间戳排序的 UI 会把刚改的卡显示为陈旧）
