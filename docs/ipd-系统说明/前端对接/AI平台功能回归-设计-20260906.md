# AI 平台功能回归前端 — 设计（2026-09-06）

> owner 指令：后端所有功能（AI 对话、知识库等）前端要按原有功能一一完整展示。
> owner 已拍板形态：IPD 侧边栏底部加「AI 平台」分组；ZK-IPD 原型 15 项菜单一格不动（是加不是改，不破 D2 红线）。

## 根因（三个都实测确认）

1. **入口断**：菜单走后端动态菜单（`accessMode: 'backend'`），但 `ipd-guard.ts` 的 `buildAccessMenus` 只装 IPD 15 项菜单树，且 `identityDestination` 把所有非 `/ipd` 路径强制弹回工作台——原平台页面（chat/knowledge/agent/mcp/…）既无菜单也无法进入。
2. **票不通用**：IPD 登录发 loginType=ipd 的 JWT（`IpdAuthSession`，独立 StpLogic）；原平台接口（/chat/**、/system/menu/getRouters 等）认基线 Sa-Token（loginType 默认）会话。拿 IPD 票调平台接口=401。
3. **数据都在**：sys_menu 182 条（对话管理/智能体/MCP/工作流/我的任务/系统管理/系统监控/系统工具/租户管理，知识库挂对话管理下）；sys_user 4 个 QA 账号且已绑角色（ipd-admin→superadmin、ipd-leader→ipd_group_leader、ipd-market/ipd-rd→ipd_pm）；页面文件基座全带。唯一数据问题：sys_user.ipd-admin status='1'（停用），其余三个为 '0'。

## 方案

### 后端（唯一后端改动：换票端点）

- 新增 `POST /api/v1/auth/platform-token`（控制器放 ruoyi-admin，与 AuthController 同层——ruoyi-admin 同时依赖 ruoyi-system 与 ruoyi-ipd，零 pom 改动；IpdWebSecurityConfig 对 /api/v1/** 的登录拦截自动生效，换票必须持有效 IPD 会话）。
- 流程：`session.currentPerson()`（IPD 会话+凭证标记校验）→ scope 必须 FULL（待改密/冻结移交拒绝）→ 按 `person.username` 精确找 sys_user；找不到（中文名真实人员）按 personType 兜底映射 SUPER_ADMIN→ipd-admin、GROUP_LEADER→ipd-leader、MARKET_PM→ipd-market、RD_PM→ipd-rd → `TenantHelper.dynamic(tenant, … buildLoginUser)` 构建 LoginUser（角色+权限照常 RBAC）→ `LoginHelper.login` 签发基线 JWT → 返回 `{token, tokenType, expiresIn, platformUser}`（code=0 包络）。
- 权限不放大：平台侧权限=被映射 sys_user 自己的 RBAC（superadmin 等已绑定）。绝不把 Person.id 写进基线会话（IpdAuthSession 既有红线不破，写的是 sys_user 的 userId）。
- 失败语义：无可用平台账号 → 404 + code0 包络错误码（非 500）。
- 数据修正：`UPDATE sys_user SET status='0' WHERE user_name='ipd-admin'`（种子误标停用；app 账号 DML，不走 DDL）。

### 前端（四点）

1. **登录后换票**：`store/ipd-auth.ts` login 成功且 FULL → 调 `/auth/platform-token` → `accessStore.setAccessToken(平台票)` + vben userStore 填 userInfo（/system/user/getInfo）。换票失败不阻断 IPD 登录（AI 平台分组降级隐藏）。
2. **guard 放行**：`identityDestination` 增加第三参 platformReady；已登录 FULL 且持平台票时放行非 /ipd 路径；否则维持弹回工作台。首次进入 AI 平台区时用 `generateAccessible`（照 access.ts 既有模式）把 `/system/menu/getRouters` 动态菜单转为路由 addRoute + 与 IPD 菜单树合并进 accessMenus。
3. **侧边栏分组**：`layouts/ipd.vue` nav 底部加「AI 平台」小节，条目取自 accessMenus 中非 /ipd 顶级菜单（数据驱动，无权限的根自然不出现）；沿用现有 sidebar 样式与折叠行为。
4. **会话联动**：IPD 登出/清会话时同步清平台票（best-effort 调基线 /auth/logout）；平台票过期（active 30 分钟）在 request.ts 401 分支先用有效 IPD 票重换一次再重试，重换失败清平台票弹回 /ipd 工作台，绝不跳基线登录页。

### 范围

- 以基座 04bb27d 自带页面为准：chat（含知识库）、agent、mcp、aiflow、workflow、tool、nodeManage、graph、monitor、system、dashboard。后端多出的 media/short-drama/coding 接口无原生前端页面，不在本次范围。
- IPD 页面/菜单/接口零改动；IPD 登录契约（单 token 轮换）零改动。

- 换票把平台能力授予所有 FULL 人员（映射后仍受 sys_user 角色约束）；超管类菜单（system/monitor/tool/tenant）仅映射到 superadmin/ipd 角色对应者可见，普通 PM 只见业务菜单。
