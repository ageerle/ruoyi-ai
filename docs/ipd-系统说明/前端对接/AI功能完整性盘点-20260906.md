# AI 功能完整性盘点（对照上游 ageerle/ruoyi-ai，2026-09-06）

> owner 问：「系统性对照上游 ruoyi-ai，你确定 AI 功能完善了吗？标准功能完整实现了吗？」
> 诚实回答：**不能说完善**。管理端齐了；用户端整块没有；运行态一次真实 AI 调用都没跑通过。证据如下。

## 一、上游是什么形态（对照基准）

上游是六仓库生态，不是单一系统：

| 仓库 | 角色 | 上游功能 |
|---|---|---|
| ruoyi-ai | 后端 | 模型管理/知识库 RAG/MCP 工具/工作流/多智能体/媒体生成/短剧/编程助手 |
| ruoyi-web | **用户端前端** | C 端 AI 对话（多会话/SSE 流式）、语音、绘图、音乐、视频、Dify/Coze 对话 |
| ruoyi-admin | 管理端前端 | 后台管理：厂商/模型/知识库/智能体/MCP/工作流/系统管理/监控 |
| ruoyi-drama | 短剧前端 | 短剧独立产品 |
| ruoyi-copilot | 浏览器副驾 | 独立副驾产品 |
| ruoyi-uniapp | 小程序 | 移动端 |

## 二、本项目有什么（逐项对照）

### 管理端：✅ 与上游一一对齐

- 证据：上游 ruoyi-admin（GitHub API 实测）views 目录 = `_core/agent/aiflow/chat/dashboard/graph/knowledge/mcp/monitor/nodeManage/system/tool/workflow` 13 个，与本地基座完全一致（本地仅多 ipd 域）。
- 后端 ruoyi-chat 16 控制器 + aiflow 4 控制器全部有对应管理页面/菜单（sys_menu 9 组 44 项）。
- 换票桥（platform-token）已打通 IPD 账号进平台（2026-09-06 AI-REG-01/02）。
- media/short-drama/coding 三组接口**上游管理端本来就没有页面**（属用户端功能域），本项目无页面不算管理端缺口。

### 用户端：❌ 整块缺失

- 上游 ruoyi-web 提供的 C 端 AI 体验本项目完全没有对应物：
  - **多会话 AI 对话（SSE 流式）**：后端 `POST /chat/send` 存在，但前端仓库零调用（api/chat 只有 chatconfig/message/model/provider 四个管理用模块，无 send）。管理端只有「聊天消息」管理页（看记录），没有对话页。
  - **RAG 知识库对话**：依赖上条，同样无入口。
  - **AI 绘图/音乐/视频**（MediaGenerationController）、**短剧**（ShortDramaController + ruoyi-drama）、**编程助手**（CodingController/CodingHarnessController）、**Dify/Coze 平台对话**、**语音/小程序**：均无前端。
- 本项目的替代物是 IPD 域自研「AI 副驾」（/ipd/ai-assistant，AiModelConfigController /api/v1/ai-models + AiDocumentController）——面向 IPD 业务的辅助生成，不是通用对话产品。

### 运行态：⛔ 一切 AI 功能是空壳

- chat_model 0 行（对话/向量/重排模型全无配置）、ai_model_configs 0 行（IPD 副驾模型配置全无）。
- 无任何 AI API key（backend-secrets.json 只有 jwt/monitor；原版 SQL 种子 key=sk_xx 占位）。
- 无向量库进程（weaviate/milvus/qdrant 均无监听）。
- 结论：**本机没有跑通过任何一次真实 AI 调用**——对话、知识库、副驾全部无法产出内容。设计文档验收条款「流式对话发一轮」从未满足过。

### 已知小缺陷

- 消息中心 SSE 推送 text/plain MIME 报错（console 存量报错，待修）。

## 三、深度反思（为什么之前敢说"完成"）

1. 之前的功能回归卡把范围定义为「基座自带页面」，这等于只对齐了上游**管理端**；「AI 功能」在用户直觉里首先是"能对话"，这部分从一开始就不在范围里——范围声明本身掩盖了缺口。
2. 换票桥解决的是"进得去"，运行态没解决"用得了"：没配模型，进去了也是空列表（模型下拉为空、知识库建不了）。
3. AI 副驾是 IPD 产品的合理自研替代，但它不能代表 ruoyi-ai 的标准 AI 能力已复用。
