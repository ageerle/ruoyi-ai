## 1. 目标

把 WorkbenchService.summary() 里散落的"按域聚合任务"逻辑抽成可插拔接口，让新增一类任务只新增一个 Aggregator 实现，不用改 summary() 主流程。P0 阶段已经在 summary() 里内联了 stage_sign 和 deletion_review 两个聚合，P1 把它们抽出来 + 新增 7 个聚合（覆盖 9 类已就绪域）。

## 2. 接口设计

新增 `org.ruoyi.ipd.workbench.WorkbenchAggregator` 接口：

```java
public interface WorkbenchAggregator {
    /** 该聚合器对应的 taskType 字符串（spec 页03:165 权威枚举 17 个之一）。 */
    String taskType();

    /** 收集当前 actor 可见的该类任务，返回 task 卡列表（字段与 P0 stage_sign 同构）。 */
    List<Map<String, Object>> collect(IpdActor actor, Map<Long, Project> visibleProjects, Date now);
}
```

接口方法三个参数的设计取舍：
- `actor`：当前登录人，决定责任匹配（PM/组长/超管看到不同行集合）
- `visibleProjects`：actor 可见的项目 Map<Long, Project>（避免每个 aggregator 重复查 visibleProjects）
- `now`：统一的时间戳，跨 aggregator 保持 overdue 判定一致性

返回的 task Map 字段约束（与 P0 stage_sign 一致）：
- 必填：id / projectId / projectName / projectCode / actionCode / title / taskType（=taskType()） / status / priority / ownerRole / dueDate / isBlocking / deepLink
- taskType 字段值由 aggregator 自己赋（== taskType()），summary() 不重复设

## 4. WorkbenchService 改造 diff

summary() 主流程从现在的"两段内联代码"改为：

```java
public Map<String, Object> summary(IpdActor actor, Long projectId) {
    Map<Long, Project> byId = visibleProjectsById(actor);
    List<Map<String, Object>> tasks = new ArrayList<>();
    Date now = new Date();
    for (WorkbenchAggregator aggregator : aggregators) {
        tasks.addAll(aggregator.collect(actor, byId, now));
    }
    long overdue = tasks.stream()
        .filter(t -> t.get("dueDate") instanceof Date d && d.before(now))
        .count();
    // ...stats 与 result 组装不变
}
```

注入方式：构造器注入 9 个 aggregator。WorkbenchService 不再用 stageActionMapper / deletionRequestMapper 直接调 selectList（移交给 aggregator 自己持有）。

## 7. 验收策略

每个 Aggregator 必须有独立单测（@Tag("dev")）：
- 正常路径：actor 是该类责任角色 → 1+ 条 task
- 边界：actor 不在责任范围 → 0 条
- overdue：dueDate < now → priority=high
- isBlocking 值域对齐 '1'/'N'（P0 修过的 bug 不能复发）

WorkbenchService 集成测试保持原有 8 用例，但 mock 改为 9 个 aggregator（而非 4 个 mapper）。

前端适配（一次性改）：
- stats.pendingType 展示：4 metric 卡增加"按类型"下拉
- taskType 过滤 tab（B4 拍板②）：17 个 tab，count 从 stats.pendingType 取
