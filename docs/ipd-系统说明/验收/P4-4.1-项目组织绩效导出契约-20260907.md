## 2. 导出契约（不写代码，规范层文档）

### 2.1 三导出 endpoint 契约

| Endpoint | 授权 | 入参 | 出参 | 审计 | 限制 |
|---|---|---|---|---|---|
| `GET /api/v1/reports/allowance/export` | SUPER_ADMIN / FINANCE | `month` (YYYY-MM), `projectId?`, `personId?` | `ReportExportResult` | `EXPORT_REPORT` action=ALLOWANCE_LEDGER | MAX_EXPORT_SIZE=5000 |
| `GET /api/v1/reports/bonus/export` | SUPER_ADMIN / FINANCE | `projectId?`, `status?` | `ReportExportResult` | `EXPORT_REPORT` action=BONUS_POOL | MAX_EXPORT_SIZE=5000 |
| `GET /api/v1/reports/project-summary/export` | SUPER_ADMIN / PM | `month`, `productId?`, `keyword?` | `ReportExportResult` | `EXPORT_REPORT` action=PROJECT_SUMMARY | MAX_EXPORT_SIZE=5000 |

### 2.2 ReportExportResult 字段契约（已是 record）

```
exportType   : String   // "allowance" | "bonus" | "project"
totalCount   : int      // 命中行数（不超过 5000）
headers      : String[] // 中文列头
rows         : Map[]    // 数据行（键为列名，值为字符串化的展示值）
filters      : Map      // 实际应用的筛选条件
exportedBy   : String   // 操作者登录名
exportedAt   : String   // ISO-8601 时间戳
```

### 2.3 一致性约束（BR-INC-15）

- **同口径**：列表查询与导出口径必须完全一致（month + productId + keyword + actor 可见集）
- **同筛选**：导出 filters 必须回显在 ReportExportResult.filters 中，便于审计复核
- **金额精度**：`BigDecimal.setScale(2, HALF_UP)`，单位元（人民币）
- **权限可见**：actor 不可见的项目 / 人员必须从导出集合中过滤掉（非仅过滤列表）
- **审计独立事务**：`appendExportAudit` 走独立事务，失败不阻断导出业务

## 4. 残留风险

1. **前端消费契约未确认**：rows 是 `Map<String, Object>`，前端需按 headers 顺序取值；目前无 OpenAPI schema 强约束
2. **导出格式限定 CSV/Excel 未明确**：当前返回 `Map[]` 由前端自行转换，未约定二进制流（HttpMessageConverter）
3. **并发导出未限流**：同一 actor 短时间内多次导出没有 rate-limit；可被穷举刷审计
4. **审计失败不影响导出**：注释明确"独立事务，失败不阻断业务"，但若审计链路坏，会丢审计未告警
5. **actor 可见集与列表不一致的可能**：actor 范围筛选在 Service 层 / Mapper 层两处，需 lint 防漂移
