### 2.3 Service 实现（sub-task 2）

- `HandoverService.scanOverdueDrafts(IpdActor operator)`：

AND isNull(escalated_at)`（first-writer 守卫并发）
  - **每日提醒路径**：`status=DRAFT AND deadline_at < now AND (last_remind_at IS NULL OR last_remind_at < today_start)` ⇒ `notificationService.publishDaily(...)`（dedupKey 自带 `yyyyMMdd` 同日去重，次日自动重发）+ `AuditLog(action=HANDOVER_DAILY_REMINDER)` + `update SET last_remind_at=now`

  - **事务边界**：方法级 `@Transactional(rollbackFor = Exception.class)`；超期集合正常极小，事务时长可控
  - **调度入口**：`@Component HandoverOverdueScanner.dailyOverdueScanJob()` 与 `PersonResignEscalator.dailyEscalationJob()` 风格一致，cron 表达式注释掉等待 OPS-04 启用 `@EnableScheduling`
