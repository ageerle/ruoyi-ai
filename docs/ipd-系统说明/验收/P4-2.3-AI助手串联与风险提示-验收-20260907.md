## 3. 业务串联完整性（链路图）

```
GENERATED（v1 原始）── review ──> REVIEWED ── archive ──> ARCHIVED（终态）
                              └─ reject ─> REJECTED ──>（重新走 review）
```

- **GENERATED → REVIEWED**：条件 UPDATE，幂等不覆盖首位审核人；ARCHIVED 行拒绝。
- **GENERATED → REJECTED**：仅 REVIEWED 行可拒绝（GENERATED 状态先 review；REJECTED 幂等；ARCHIVED 终态不可拒）。
- **REVIEWED → ARCHIVED**：未审核（含 REJECTED 重审前）拒绝，固定字面量「AI 文档须人工审核确认才可归档」对外文案（AC-AI-03）。
- **并发防分叉三层防线**：服务层 HEAD 校验 → DB 层 uk_ai_doc_parent 唯一索引 → DuplicateKeyException 映射 STATE_CONFLICT。
- **contentSha256**：每版本 SHA-256 摘要，diff 用作同链完整性回查。
