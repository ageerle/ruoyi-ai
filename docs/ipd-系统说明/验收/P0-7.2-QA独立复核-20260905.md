## 三、验收要点逐条判定

### AC-AUTH-02：首登强制改密

**判定**: ⚠️ **部分满足（本仓静态可核验部分满足，动态行为不可核验）**

| 检查项 | 状态 | 证据 |
|--------|------|------|
| must_change_pwd 字段存在 | ✅ | Person.java |
| scopeOf 返回 PASSWORD_CHANGE_REQUIRED | ✅ | IpdAuthService.java |
| IpdPermission 拦截非改密接口返回 403/20003 | ✅ | IpdPermission.java |
| login() 响应含 mustChangePwd 字段 | ✅ | IpdAuthController.java |
| 改密后 mustChangePwd 清零 | ✅ | IpdAuthService.java |
| 首登后其他接口返回 403/20003 的动态行为 | ❓ | **本仓不可核验** |
| 前端强制跳转改密页的联调 | ❓ | **本仓不可核验** — 前端仓库范畴 |

### AC-AUTH-03：改密后旧密码失效 + 旧密码失败写审计

**判定**: 🔴 **不满足（存在实现缺陷）**

| 检查项 | 状态 | 证据 |
|--------|------|------|
| 改密后凭证标记失效（旧 token 401） | ✅ | IpdAuthSession.currentPerson() |
| changePassword 成功后 revokeAll 撤销旧会话 | ✅ | IpdAuthController.java |
| **旧密码 changePassword 失败写 PASSWORD_CHANGE_REJECTED 审计** | ❌ | **缺陷确认** |

**缺陷详情**: IpdAuthService.changePassword() 在旧密码错误时抛出 ServiceException 而非 IpdAuthInputException，导致 IpdAuthController.password() 的 catch 块永不执行，审计代码成为死代码。

**修复建议**: IpdAuthService.changePassword() 第112行应改为 throw new IpdAuthInputException(IpdAuthInputException.Reason.CURRENT_PASSWORD_INCORRECT);

### AC-HAND-01b：冻结态仅移交接口可用
