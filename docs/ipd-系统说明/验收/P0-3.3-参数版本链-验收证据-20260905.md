版本链语义：每次 update 在同一事务内——①首个版本前先落**基线行 v1**（旧值，effective_from=本体行 create_time，回溯锚）；②闭合当前开区间行（受控 lambdaUpdate 仅改 effective_to，全代码库唯一允许的版本行 UPDATE）；③追加新行（version=last+1，effective_from=now，effective_to=NULL，is_immutable=1）。时点解析：`effective_from ≤ T ＜ effective_to(或 NULL)`，无命中回退出厂默认 defaultValue。
