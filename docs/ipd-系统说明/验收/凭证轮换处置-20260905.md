## 4. 交 owner 裁决的一件事（我不擅自决定）

`application-dev.yml:17` 的 dev 默认值**保持现状**还是**置空为 `${IPD_INITIAL_PWD:}`**？

- 置空的收益：仓库里种子口令明文从 17 处降到 16 处，dev 与 prod 形态一致。
- 置空的代价：任何未注入 env 的 dev 启动会拿到空种子口令（父基线无默认 → fail-fast 或写入空 hash），**静默打断**所有并行会话的本地起服与 P0-9.1 类探针。
- 我的判断：F2 已证明真正的泄露面是「活库 11 个账号共用同一口令」，而不是这行 yml。R1–R3 完成后该默认值只影响全新灌种子，届时置空才是零成本收口。因此本批**不动它**，把选择权留在 owner。

- 本批只做到「**代码/测试侧不再有第二份凭证载体**」+「**文档侧明文可计数**」。**凭证本身尚未轮换**：F2（21:06:40）就是当前仍共用的直接证据，本项不得标 done，只能标 **PARTIAL**。
