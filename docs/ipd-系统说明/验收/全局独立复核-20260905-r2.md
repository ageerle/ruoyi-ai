- **并发写风险（最高）**：多会话同改 SSOT/看板/同一 Java 文件会触发未纳管/重复卡拒绝与漂移（本轮 P0-6.2/P1-2.1 亲历卡死→自愈）。缓解：drift 归零窗口内一次性 `set`，其余只读 + 证据交付。
