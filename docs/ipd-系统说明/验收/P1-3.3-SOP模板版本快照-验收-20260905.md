## 二、核心语义（BR-IPD-07 / AC-IPD-27）

- **版本机**：DRAFT --publish--> PUBLISHED --被新版本替代--> ARCHIVED；同 actionCode 至多 1 个 PUBLISHED/DRAFT；全程条件 UPDATE（`where status=...`）守卫并发（影响行数 0 → 409）
- **快照**：bootstrap/instantiate 时 stage_actions.sop_id = 当时 PUBLISHED 的模板 id；publish 新版不改既有行 → 在研项目取 SOP 走 get(sopId) 永远读旧版内容
- **AC-IPD-20**：publish 时对生物特征动作（ActionCatalog.bioFeature：V10/C12/D11）强制校验 content 含「算法公平性」与「偏见测试」，缺则 400
- **停用不破坏历史**：ARCHIVED 只读可查（get 不限状态），软删走 P0-6.2 既有机制
- **审计**：COPY/UPDATE/PUBLISH/REVERT，entityType=SOP_TEMPLATE，before/after 含 version/status/title/contentSha/contentLen（diff 语义，不重复落正文）；operator 取会话 actor（SEC-01 契约，零客户端 operatorId）
