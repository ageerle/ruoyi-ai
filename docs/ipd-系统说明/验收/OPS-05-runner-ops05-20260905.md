## 验收口径对照（AC-TEAM/GATE/DEL 场景底座）

- **统一接收者/业务来源/去重键/已读**：`receiver_id + source_type/source_id + dedup_key(uk) + read_flag/read_at`；用例 `publish_insertsPendingRowWithMockChannel`、`inbox_receiverScoped`、`unreadCount_scoped`。
- **事件可重试**：`dispatch_failure_backoffThenDead`（retry=1 失败→FAILED+count2+退避 10min=5·2¹；retry=2 失败→DEAD 死信）；`dispatch_dueFilterInQuery`（仅扫退避期满行）。
- **跨组知会与审批行动分开**：`kind` FYI|ACTION 硬校验 + 用例 `kind_fyiAndActionSeparated`（AC-DEL-04 知会 vs Gate 签署行动）。
- **一期 Mock 渠道标识清楚**：`MockNotificationChannel.CODE="MOCK"` 落 `channel` 列；用例 `mockChannel_markerContract`；实体/渠道注释均声明 SENT+MOCK ≠ 站外送达。
- **同一事件只执行一次**：uk_notify_dedup 兜底 + `publish_duplicateDedupKey_returnsExistingOnce`；多接收者独立去重 `publish_sameEventDifferentReceivers_independentRows`（AC-TEAM-05）。
- **并发双消费守卫**：`dispatch_concurrentSkip`（条件 UPDATE 影响 0 行 → skipped）。
