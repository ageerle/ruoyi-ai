## ② nextcode-unique.sql 必 1061（MED）——幂等化改写

**问题**：原脚本对 `projects` 裸执行 `ADD UNIQUE KEY uk_projects_code (code)`，而基线建表已含同名键 → 「按主 DDL 建库」环境必报 ERROR 1061，脚本不可重放。同文件还试图加复合键 `uk_projects_product (product_id, del_flag)`，与基线同名键（单列 product_id）列集冲突。

**修法**（改写 `2026-09-05-ipd-perf01-nextcode-unique.sql`）：
- `uk_projects_code` 改为可重复执行：MySQL 8.0 无 `DROP INDEX IF EXISTS`/`ADD INDEX IF NOT EXISTS`，用 `information_schema.statistics` 判断 + `PREPARE` 动态 SQL：不存在→补建；存在且列集为 `(code)`→跳过；存在但列集不同→`SIGNAL SQLSTATE '45000'` 终止人工核查（防同名异列静默漂移）。
- 复合键 `uk_projects_product(product_id, del_flag)` **不执行**，脚本内以注释块给出 A/B 两方案对比 + 推荐理由，标「owner 裁决项」（见文末清单）。
