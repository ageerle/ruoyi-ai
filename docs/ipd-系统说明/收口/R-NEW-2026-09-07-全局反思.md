### Why（为什么有这些遗漏）

1. **WAVE14 之后新增 P2-5.6/P4-1.4 commit（PostLaunchReview + RequirementStateMachine）未被 IDOR 全仓扫捕获**——W5-E 扫基于当时基线,新增代码天然豁免。

3. **PostLaunchReviewService 缺 Controller**——实现优先于 API 暴露,典型的"先做后端再补前端"开发节奏产物。
4. **AI/RAG 模块审查资源倾斜 ipd-chat**——P4-2.2 集中收口 AiChatClient,AiGenerationService 上游 + coding harness 下游未做端到端重审。
